# 評価用ゲームの実装仕様

## 入口と設定

入口の「ゲームを始める」から、保存済み `public/data/cards.json` を使う一局を開始する。
「カード設定を開く」は `#settings` の既存エディターを開く。
エディターから入口への移動はページ遷移とし、未保存変更の確認とWorkerの破棄をブラウザに任せる。
保存した設定は入口を開き直した際に読み込まれ、次のゲームに反映される。

開始前に構造検証と制作途中の検証を行う。未設定の目標・効果はカードIDとステップを示して開始を拒否する。
設定の自動補完は行わない。ゲームはカード定義を複製し、カードのステップやダイス面変更を設定へ保存しない。

## 状態と責務

- `src/game/engine.js`：初期配置、カード領域、日数、名声、信用、チラシ、進行操作。
- `src/game/dice.js`：乱数注入、シャッフル、初期面、獲得候補、指定面、ロール。
- `src/game/goals.js`：現在の未使用ダイスによる厳密な達成判定。
- `src/game/effects.js`：全16効果、対象選択、獲得・ストック取得、特殊面の対象固定。
- `src/game/view.js`、`view.css`：情報表示、対象選択、結果、再プレイ。

カード状態は `{ id, step }` とし、同一カードを領域間で移動する。
領域は `deck`、`hand`、`field`、`discard`、`shipped`、グレード別 `stocks`。
`public` は各ストックで公開中のカードIDか `null`。取得後はリフレッシュまで公開しない。

ダイス状態は一意のID、6面、現在面の番号、消費状態、所持期間を持つ。
通常面は `{ color, material }`、特殊面は `{ special }`。
消費済みも所持領域に残り、破棄時は所持領域から取り除く。

## 進行と選択待ち

進行は `start` → `play` → `end` → `betweenDays`、信用0で `finished`。
最初の日はゲーム開始と同時に開始し、翌日は「翌日の仕事を始める」で開始する。
ターン終了後を明示的に区切り、予約効果や信用の更新を記録で確認できるようにする。

効果処理はGeneratorで配列順に実行する。選択が必要な場合に `pending` を返し、処理を中断する。
`pending` は対象種別、説明、候補ID、選択数の下限・上限を持つ。
`choose(ids)` は候補外、重複、不足、超過を拒否し、有効な選択だけで再開する。
中断中はプレイ・達成・リロール・ターン移行を拒否する。対象なしは選択を要求せず処理を完了する。

通常ダイスを複数獲得する場合、1個ごとに候補生成と選択を行い、全選択後にまとめてロールして加える。
手札交換は、返却・必要時の公開・手札への取得を1回ずつ完了させる。
特殊面の即時適用は対象を発動時に固定し、名声、リロール権、ドロー、一時ダイスの順で処理する。
新規獲得ダイスは今回の対象へ追加しない。

達成は目標をORで分割し、各AND条件に異なる未使用通常面ダイスを割り当てる。
選択したダイスは、そのOR候補の目標数と同数で、すべてが割り当て可能な場合だけ受け付ける。
達成時効果より先に消費し、全効果完了後にステップと領域を更新する。
確率表示の近似計算は判定に利用しない。
プレイフェーズの終了は任意とし、手札枚数や達成可能な場札の有無で制限しない。効果の選択待ち中は終了できない。

ターン終了時は特殊面予約、通常面最大2個のチラシ制作、自動発注、信用更新、終了判定の順に処理する。
チラシ用ダイスは色・画材を問わず同じ結果になるため、所持順の先頭から選ぶ。使用IDを記録する。
継続する場合にクリーンナップとストック更新を行う。信用0の場合は終了時点の領域を残す。
翌日の開始を待つ間は、信用更新後・クリーンナップ前に複製した `dayEndDice` を表示する。
一時ダイスも含む当日の出目と消費状態を確認でき、「翌日の仕事を始める」で終了時の表示を解除する。
この確認用の表示からダイスを使用することはできない。

## 評価画面

日数、進行状態、名声、信用、チラシ、リロール権、領域の枚数と公開情報を表示する。
手札、制作中、公開ストック、出荷済み作品では現在ステップと全ステップの目標・効果を確認できる。
絵画は既存の完成図を詳細内に表示する。制作途中の見た目や正式な演出は扱わない。
ダイスは6面を共通の面アイコンで常時表示し、その中で現在面を強調する。所持期間・消費状態は文字で維持する。

達成用のダイスをチェックし、「選択ダイスで達成」で確定する。
有効な組合せを選ぶまで達成ボタンを無効化する。達成可能表示は未使用の現在面から更新する。
手札にも現在ステップの目標を満たせる場合に「達成可能」と緑の枠を表示する。プレイ時効果による将来の出目変更は予測しない。
効果の選択待ちでは対象と必要数を表示し、確定までは他の進行操作を無効化する。
画面上部に進行情報、下部に直近の処理と仕事終了・翌日開始ボタンを固定する。
制作画面では左にダイス、中央に制作中の作品、右に手札を配置する。
領域内のスクロールを独立させ、操作後も各領域の位置を保持する。画面全体の上下移動は必要としない。
ダイスの個別リロールは矢印ボタンで行い、対象IDをアクセシブルな名前とツールチップで示す。
狭い画面ではダイスを左列、制作中と手札を右列の上下に配置する。
公開ストック・出荷済み・記録は情報タブで切り替え、ダイスと進行操作は常に表示する。
効果の対象選択はモーダルダイアログで行い、選択候補だけを内部スクロールし、確定操作を下部に残す。
カードの上段にID・カード名、右端に現在ステップを表示し、グレードはIDから判別する。
その下に目標・プレイ時・達成時を表示する。プレイ時・達成時の効果がない行は、全ステップ表示も含めて省略する。
下段の左側にプレイ・達成の操作、右側に「全ステップ表示」を置き、詳細と完成図を開閉できる。
制作中と手札はそれぞれ横1枚の1列表示とする。
カード内の目標は黄土色、プレイ時効果は青、達成時効果は緑の文字・淡い背景・左罫線で区別する。
効果説明は `画材指定ダイス獲得(x1) / 一時 / 絵筆` のように個数・回数を効果名の直後へ置く。
所持期間・画材・色などの項目ラベルは表示せず、名声の増加値には `+` を付ける。未設定値は「未設定」と表示する。

終了時は日数・名声・出荷数と再プレイ操作を表示する。
一局の記録はメモリー内だけに保持し、途中保存や過去記録との比較は行わない。
進行記録は効果、使用ID、カード移動、チラシ制作・発注、信用減少、終了を記載する。

## 検証

`tests/implementation/game/` は進行の中断・再開、データの分離、目標割当、ダイス生成を確認する。
`tests/spec/rules_01_game_flow.test.js` は終了までの操作列、45枚の保存則、出荷時の信用増加、発注と予約を確認する。
`effects_06_game_dice.test.js` と `effects_07_game_other.test.js` は全効果と特殊面10種類を実行する。
乱数はGameの第2引数から差し替え、面構成、ロール、シャッフルを再現可能にする。

## カードの共通アイコン

手札・制作中・公開ストック・出荷済み作品の全ステップ表示と、カード対象選択は同じカード表示部品を使う。
現在ステップの目標・プレイ時・達成時効果、および全ステップの詳細に `src/cardIcons.js` の共通アイコンを表示する。
目標はANDの表記を入れず、ORを縦棒「|」で示す。効果は設定順に並べ、番号や矢印を付けない。現在ステップは文字で示す。
各アイコンはホバー・キーボードフォーカスで説明を表示し、アクセシブル名でも意味を示す。
表示側に完成状態の再検証や値の補完を追加せず、開始時に検証したカード設定を共通描画APIへ渡す。

## 使用済みダイスの再利用

`refreshDice`は対象選択なしで、所持する全ダイスのusedをfalseへ戻す。
永続・一時、通常面・特殊面を区別せず、現在面・面構成・リロール権は変更しない。
所持ダイスなし・使用済みなしでも処理を完了し、次の効果を続ける。
プレイ時・達成時のどちらにも設定でき、達成時は直前の達成で消費したダイスも対象になる。

## カード行とダイス面の表示

カードの「目標」「プレイ時」「達成時」はラベルとアイコンを同行に置き、ラベルだけで1行を占有しない。
全ステップ表示ではステップ番号・現在ステップを見出しとして示し、各情報行には同じ配置を使う。
ダイス面は`src/dice/icons.js`の`faceCanvas`を再利用し、6面の構成・獲得候補の面を表示する。
6面の各アイコンは22pxで縦横比を維持する。6面は常時横へ並べ、領域が足りない場合だけ折り返す。単独の現在面表示と6面の開閉操作は設けない。
6面内の現在面を枠・背景と「現在」の文字で示す。ホバーとフォーカスで色・画材・特殊面の説明を表示する。
選択チェック、リロール、所持期間・使用状態の操作と表示は維持する。

通常ダイスの獲得候補は効果の所持期間（lifetime）を保持し、候補の6面もその期間に対応するアイコンで描く。
