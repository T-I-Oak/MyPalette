# 捨て札エリア

## 表示

- 固定倍率のエリア名は「捨て札 N枚」。Nは共通管理が保持する表示上の捨て札枚数。
- 背景は透明。空でもエリア名と領域を維持する。
- デッキと同じ標準サイズ454×609を使用する。エリア名用の上部36は別枠。
- カード294×414、左右±24、上下±8、回転±10度の最大外接範囲に、45枚分の厚み66、持ち上げ24、上下左右22の余白を加えて計算する。
- デッキ自身のずれ幅は左右±1、上下±0.45、回転±1.5度を維持する。
- 捨て札は表向きで、最後に加わったカードが上。ずれはカードごとに保持し、再描画・リサイズで変化させない。

## 情報確認

- 見えているカード面をクリック／タップすると、そのカードの既存詳細表示を開く。
- 山にあるカードのステップタブは操作せず、詳細表示で各ステップを参照する。参照でゲーム状態は変化しない。
- 隠れたカードを閲覧するための一覧や山の展開は設けない。捨て札内容全体を公開情報とは扱わない。

## 捨て札への移動

コンポーネントを実在する物のように扱い、表示位置が突然切り替わる動きを避ける。

- 達成後、次ステップのカード表示が戻ったら、そのカードをイーゼルから捨て札へ520msで移動する。到着後に達成時効果を解決する。ステップ3は出荷なのでこの移動を行わない。
- 日末は、手札・制作中の全対象カードを同時に300msで移動する。到着先の重なり順はゲーム状態の捨て札順に合わせる。同じ実カードを現在の位置から連続して移動し、残るカードとイーゼルの再配置も補間する。移動用の複製・非表示は行わない。捨て札への移動中はストックも元の公開状態を保持し、到着後にストックの日末更新演出を始める。
- 効果・チラシ発注によるストック取得は、公開カードを元のストック位置から表向きのまま520msで捨て札へ運ぶ。移動前のストック表示と枚数を保持し、到着後に次の公開カードの演出を開始する。
- 最後の発注選択と同時に日末回収が進む場合は、取得カードと手札・制作中カードを同時に300msで運ぶ。捨て札の重なり順はゲーム状態の順と一致させる。
- 未到着カードを捨て札の表示・枚数に含めず、到着ごとに表示を増やす。
- [全エリア共通カード表示](18.card_scene.md)を使用し、イーゼル上のカードの投影行列から捨て札の位置・倍率・ずれへ補間する。元と先の座標を毎フレーム取得し、レイアウト変更やパネル開閉に追従する。閉パネルではその現在の位置へ移動し、自動では開かない。
- 動きを減らす設定は最終状態を即時反映する。入口へ戻るときは飛行表示を破棄し、後続処理を停止する。

## デッキへの再構成

朝・効果ドローとも、次の1枚を引こうとした時点でデッキが空かつ捨て札がある場合に再構成する。不足を予測して捨て札を消さない。`manualRecycle`を使うゲーム画面では`recycleRequest`を発行してゲームのジェネレーターを停止し、Step3の開始時に`completeRecycle`で再開する。シャッフルはその再開時に一度だけ行う。評価用の同期進行は待機しない。

全カードを同時に、各420msの3段階で動かす。

1. 元の捨て札の上から順に、捨て札エリアの左から右へカード中心を等間隔に並べる。左右22の余白を置く。横移動は`(1 - cos(πp)) / 2`で補間する。移動と同時に0→90度回転し、終点で最も薄い状態になる。元の位置・回転ずれを解消する。
2. 同じ横補間で捨て札の中央に集め、90→180度で裏返す。Y方向の1.5ずつの積み重ねだけを残す。
3. ゲームを再開して内部シャッフルを実行し、その確定順に裏向きの全カードをデッキへ運ぶ。移動中は捨て札0枚、到着後にデッキの枚数を反映して残りのドローを再開する。表示側で再抽選しない。

移動座標は毎フレーム取得する。再構成の間は既存の手札を表示し続け、ドロー再開時の配置変更も補間する。動きを減らす設定では待機を即時解消して最終状態へ進む。演出のキャンセル時は全移動表示を破棄する。検証は`scripts/checkRecycleMotion.cjs <開発URL>`。

2026-11-10のオーナー指示に基づく。ブラウザー検証は `scripts/checkDiscardMotion.cjs <開発URL>`、表示・参照は `scripts/checkDiscardArea.cjs <開発URL>`。

ストックから捨て札への移動と補充の接続は`scripts/checkStockDiscardMotion.cjs <開発URL>`で検証する。

実カードの個体・姿勢・表裏・枚数・動作の進行はCardSceneが一元管理する。エリア個別の描画保持・非表示・移動用複製は使用しない。
