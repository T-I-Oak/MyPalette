# ダイスコンポーネント

## 目的と入口

ゲーム本体のパレットで使用する3Dダイス単体・群・描画・検索の共通コンポーネントを提供する。
旧dev.html#diceと入口リンクは廃止し、旧ハッシュで開いた場合は通常の開発者入口を表示する。
ダイスの表示と操作はゲーム本体で確認する。

## 構成と所有

| モジュール | 責務 |
| --- | --- |
| `src/dice/Die.js` | 6面、ID、所持期間、状態、単体の物理ボディ・結果 |
| `src/dice/DiceGroup.js` | ダイス管理、共有物理空間、複数ロールの完了管理 |
| `src/dice/orientation.js` | ローカル面法線からワールド上面を判定 |
| `src/dice/pose.js` | 初期配置とprepareで共有する準備高さ |
| `src/dice/geometry.js` | 稜・頂点を丸めた描画用ダイス形状 |
| `src/dice/specialFrameLayout.js` | 特殊面を示す星型フレームの形状と配置 |
| `src/dice/faceConditions.js` / `FaceSearch.js` | 面の一致判定と検索表示の期限管理 |
| `src/dice/searchIcons.js` | 条件アイコンと一致面数の図形描画 |
| `src/dice/FaceSearchNotice.js` / `searchMessages.js` | 固定IDの検索通知と共通i18nによる文言・条件名の翻訳 |
| `src/dice/icons.js` | 通常面の記号・色文字、特殊面の共通図形と効果アイコン |
| `src/icons/glyphs.js` | 共通の色文字・数字・符号・矢印 |
| `src/icons/laurel.js` | 共通の月桂冠と名声数値表示 |
| `src/dice/resultGraphics.js` | 既存画像の読込み、着色合成、結果画像キャッシュ |
| `src/dice/colorizeGrayscale.js` | 元のアルファと明暗を維持し、指定色の色相・彩度で着色する |
| `src/dice/DiceScene.js` | 3D表示、実行ループ、リサイズ、結果表示、描画資源解放 |

描画はThree.js、物理はcannon-esを使用する。両者は同じ右手系・Y上向きを使用でき、
ボディの位置とクォータニオンをそのまま描画へ反映できるため採用する。
各依存のバージョンはpackage.json、再現可能な解決結果はpackage-lock.jsonで管理する。
公式資料: [Three.js BoxGeometry](https://threejs.org/docs/pages/BoxGeometry.html)、
[WebGLRenderer](https://threejs.org/docs/pages/WebGLRenderer)、
[cannon-es World](https://pmndrs.github.io/cannon-es/docs/classes/World.html)。

群は物理Worldと床・境界・各ダイスを所有する。
シーンはRAF、ResizeObserver、WebGLRenderer、ジオメトリ、面テクスチャ、マテリアル、
照明、結果DOM、画像キャッシュを所有する。画面終了・pagehideでシーンを破棄し、群も破棄する。
ダイス削除時は次フレームで対応するメッシュ・テクスチャ・結果DOMを解放する。

## 単体API

`new Die({ id, faces, lifetime, position })` で生成する。
群に追加する場合は `group.add(options)` を使用する。
IDは空でない文字列、facesは6要素。面は `{ color, material }` または `{ special }`。
識別子と特殊面は既存の `effectCatalog.js` を正本とする。
面データはコピーして凍結し、外部からの書換えを避ける。
所持期間は `permanent` / `temporary`。生成後の変更は対象外とする。

| API | 契約 |
| --- | --- |
| `id`, `faces`, `lifetime`, `state`, `consumed` | 状態参照。変更は対応するメソッドを使用 |
| `setFace(index, face)` | 0〜5の面を変更。確定中の現在面なら結果にも反映 |
| `findFaces(condition)` | 6面のうち条件に一致する面のindex配列を返す。状態は変更しない |
| `setPosition({x,y,z})` | 有限数のワールド座標へ移動。群所属時はパレットの有効範囲内へ補正。結果表示も追従 |
| `prepare()` | 以前の結果を破棄し、X/Zを維持して中心Y=4.5の空中回転状態へ戻す |
| `setConsumed(boolean)` | 所持したまま消費状態を変更。ロール対象にできなくする |
| `roll()` | 所属群の単体対象ロールへ委譲し、単体結果のPromiseを返す |
| `result` | 確定中だけ結果を返す。それ以外はnull |
| `top` | 現在の姿勢における上面indexと上向きの一致度 |
| `dispose()` | 待機中の単体結果を中止で解決し、所属群・物理空間から除去 |

`begin`、`settle`、`cancel`、`body`、`owner`は群・描画との内部接続用。
結果は `{id, status:'settled', index, face, lifetime}`。
削除・破棄時は `{id, status:'cancelled'}`、停止に失敗した場合は `{id, status:'failed'}`。
物理的に確定していない面を結果として返さない。
単体の確定通知は内部の `pending` Promiseの解決で行い、群全体の確定を待たない。

## 群API

`new DiceGroup({ random = Math.random })`。乱数はロール開始・再投入時の高さ、姿勢、並進速度、角速度に使用する。初期配置には使用しない。
ゲームのルール判定、獲得・消費の自動処理、特殊面の効果発動は行わない。

| API | 契約 |
| --- | --- |
| `add(options)` | 単体を生成・所有して返す。ID重複を拒否。最大12個 |
| `remove(id)` | ID指定で削除。ロール中も可。結果待機は中止で解決 |
| `get(id)` / `dice` | 単体参照 / 追加順の単体配列 |
| `findFaces(condition)` | 一致するダイスだけの `{id, indices, count}` 配列を追加順に返す |
| `roll(ids?)` | 指定IDを同時ロール。省略時は未消費の全ダイス |
| `rolling` | 群のロール完了待ち中かどうか |
| `step(deltaSeconds)` | 描画ループ等から物理と待機姿勢を進める |
| `dispose()` | 全待機を中止で解決、全ダイス・床・境界を解放。重複呼出し可 |

`roll` は指定順の結果配列をPromiseで返し、全対象が確定・中止・失敗した後に解決する。
選択状態と入力方法は呼出元のUIが管理する。群には選択したID配列を渡す。
確認画面はチェックボックスで選択する。3Dのダイス本体へのクリック・タップと、選択中の外観表示は未実装。
対象外の確定結果と姿勢は保持する。対象外がロール前なら空中回転は継続する。
空対象、重複ID、不明ID、消費済み対象を拒否する。全対象を検証してから開始するため、
一部だけ開始されることはない。群の同時ロール中の別ロール・追加は拒否する。
破棄後の追加・ロールも拒否する。

## 状態と停止判定

| 状態 | 表示と遷移 |
| --- | --- |
| ready | 結果なし。空中でX/Y/Z軸を異なる速度で回転。rollでrollingへ |
| rolling | 結果なし。共有Worldで衝突・落下・回転。停止でsettledへ |
| settled | 上面を保持して結果が出現・浮遊。再ロール開始時に以前の結果を消す |
| disposed | 非表示・群から除去。再利用不可 |

ロール中の面変更・prepare・移動・消費切替は拒否する。
結果の出現・浮遊は確定状態に付随する描画であり、群の完了を遅延させない。
消費は状態とは別属性。ダイス本体を暗くし、浮遊する結果（画材・特殊面）を非表示にする。未消費に戻すと保存された結果を再表示する。
破棄は本体・結果を除去するため、消費と区別できる。確認ページ・ゲームともダイス上のIDラベルは表示しない。

辺長2の剛体箱を使用する。重力はY=-18、床はY=0。境界はfield.jsに定義したパレット内側の凸多角形。
摩擦0.45、反発0.28。固定刻み1/120秒、最大6サブステップ、フレーム差分は最大0.05秒。
バックグラウンドからの復帰時に大きな差分を一度に投入しない。
各ダイス間と床・壁との衝突を同じWorldで処理する。
ロール対象だけ動的ボディにし、対象外は静的ボディとして位置・出目を保持する。

線速度・角速度がともに0.13未満で0.5秒継続し、上面一致度が0.99超、中心Yが5.3未満（水平に安定した積み重なりを含む）なら確定。
上面は6法線をクォータニオンで回転し、ワールドY成分が最大の面とする。
BoxGeometryのマテリアル順に `+X,-X,+Y,-Y,+Z,-Z` が `index=0,1,2,3,4,5` に対応する。
表示する面番号はindex+1。姿勢を別の出目に置き換える処理は行わない。
上面が確定しない傾いた静止は0.8秒の低速状態、長時間の未停止は12秒で検出して再投入する。
再投入は最大8回。再投入時は別の初期スロットへ移し、積み重なりによる引っ掛かりを避ける。投入高さは5〜7単位。なお停止できなければfailedとして再操作可能に戻し、確認画面に案内する。

## 通常面と特殊面

中央の画材記号は絵筆=しずく、パステル=角丸平行四辺形、エアブラシ=同径の3円を重ねた塗り形状。
エアブラシの円周・重なり線は表示せず、一時では白い形状の外周だけに色の縁取りを付ける。
文字中心は記号座標で絵筆Y=62、パステルY=51、エアブラシY=47。
色文字は橙O・黄Y・緑G・青B・紫P・赤R。
アイコン内の色文字・数字0〜9・符号・左向き矢印は `src/icons/glyphs.js` の共通パスで描き、インストール済みフォントへ依存させない。
色文字は閉じた太い輪郭を塗りつぶして描き、通常面と特殊面で字形を共有する。6色すべてに共通の暗い縁取りを付ける。
永続は色付き記号と白文字、一時は白い記号に色の縁・色文字。
黄色は#dbb61eを基本とする。最終的な見やすさはオーナー検証で判断する。
面画像は256pxのCanvasTextureで、背景は四隅まで不透明に塗る。確認一覧は同じ描画関数から生成する。
描画形状は辺長2・丸み半径0.28・分割数4のRoundedBoxGeometryとし、中央の平面を残して稜・頂点を丸める。
6マテリアルの順序は上面判定と共通。物理形状は辺長2の箱を使用する。

特殊面は `SPECIAL_FACES` / `SPECIAL_FACE_EFFECTS` の10種類。
名声は月桂冠と+1、ドローは手札・左向き矢印と+1、リロール権はチケット内に傾いた六角形・Y字と波紋。
月桂冠は半径36の真円弧に沿う茎と葉で構成する。汎用の `drawFameIcon(ctx, amount)` は非ゼロの安全な整数を受け、
白縁の数値をサイズ30で描く。+10も同じ大きさとし、幅70を超える場合だけ縦横比を保って縮める。減少値は赤色。
ドローの `drawCardDrawIcon(ctx, count)` は正の安全な整数を受ける。想定表示は1桁で、数値サイズは23固定。
3枚の手札を下端の共通支点から左右へ開き、右側に白縁の左向き矢印と数値を中心X=77で縦に揃える。
チケットは金色#f2ce79の横長形状に、半径3の上下の切欠きと半券の切り取り線を付ける。
中のダイスは白く塗り、右上の頂点へ向かう方向に半径6・10の波紋を置く。
一時ダイス獲得は六角形に、通常=Y字、補色=2色領域と各色文字、画材指定=共通画材記号を入れ、
左右に雲状の補助記号を付ける。×1は省略。発動タイミングと星型は含めない。
特殊面の結果表示は淡い金色の星型フレーム（共通texture-highlight-frame）とし、共通効果アイコンを透過画像として中央に置く。ダイスを指す尾は付けない。星は外半径48・内半径25の5つの先端を持ち、アイコン領域は中央の50%角とする。フレームは80〜144pxで表示し、形状の視認性と内側のアイコン領域を両立する調整案として確認する。
ダイス上面の投影位置の上方へ配置し、画面端では内側に収める。フレームの形はダイスとの位置関係で変えない。
星型フレームと画材は同じ描画構造・アニメーションを使う。
0.7秒かけて45px下・倍率0.45・透明の状態から出現し、その後3秒周期・7px幅の上下動と左右±3度の回転で浮遊させる。
星型フレームと内側のアイコンを一体で動かす。

## 結果画像と配置

`public/assets/dice/*_grayscale.png` は明暗をRGB、透過を別のアルファチャンネルに保持する。
グレーの明暗をHSLの明度に使い、出目の色から色相・彩度を与える。元のアルファ値は変更しない。
その上に同位置・同サイズの `*_fixed.png` をsource-overで合成する。
固定部分の色、画材本体の不透明さ、元画像の陰影・ハイライト・透過を保持し、元の画像ファイルは変更しない。
3画材の6画像を事前読込みし、生成結果を面データ単位でキャッシュする。
画像読み込み失敗はメッセージと再読込み・入口の操作を表示する。

結果は0.7秒でダイス付近から出現し、3秒周期で7px上下動する。
ロール開始時は非表示。演出付きprepareでは本体へ帰還した後に非表示とし、面変更時は画像を再生成する。
結果位置は毎フレーム、ダイスのワールド位置をカメラでスクリーン座標へ投影する。
画材画像の下端を本体上面の投影位置から4px上へ合わせ、幅はダイスの描画寸法の約2倍に合わせて64〜144pxで調整する。
画面端のはみ出しだけを補正し、重なり回避を理由に本体から遠くへ移動させない。
確認ページでもダイス上のIDは表示しない。共通DiceSceneはIDラベルを生成しない。浮遊する結果画像にもIDを付けない。
結果画像の重なり順はダイス中心を投影した画面Y座標の昇順とし、画面下側のダイスに対応する結果を手前に描く。位置の変化に合わせて毎フレーム更新する。
縮小表示は画面全体のCSS scaleで行わず、カメラの表示範囲とレイアウトで対応する。

カメラは正投影、位置(0,15,9)、原点を見る。
半球光・影付き平行光を使用し、床には提供された透過パレット画像を使用する。
ダイスの面背景は永続がアイボリー（#fffaf0）、一時が明るい水色（#98d5ed）。一時の記号内部は白を保つ。
照明下でも所持期間を区別できる明度差を設ける。
初期配置は4列×3行の固定配置。slotの列をc=slot%4、行をr=floor(slot/4)として、X=1.56+(c−1.5)×4、Z=(r−1)×2.5、Y=4.5で生成し、field.jsの有効範囲へ補正する。位置の乱数による揺らぎは付けない。
ロール前は3軸回転、ロール後は物理姿勢が回転・配置の揺らぎになる。

## 面構成の条件検索

条件は `{material}`、`{color}`、`{material,color}` のいずれか。識別子は既存カタログを使用する。
空条件・未知のキーや識別子は拒否する。画材＋色は同じ面が両条件を満たす場合だけ一致する。
特殊面は通常の画材・色検索に一致させない。現在の出目に関係なく6面を調べ、同じ面定義の重複もそれぞれ数える。
所持期間・消費状態では除外せず、対象選択・出目・姿勢・位置を変更しない。

`FaceSearch` は条件と表示期限を持つ。`search(condition)` の戻り値と `result` は
`{condition,hits,diceCount}`。`active` は3秒間だけtrue。同じ条件で再実行しても期限を更新する。
`result` は最新の面構成・所持ダイスで計算し、期限後も保持する。`clear()` で条件と期限を解除する。
`opacity` は同じ時計で計算し、開始から200msで0→1、終了前300msで1→0となる。

`DiceScene.showFaceSearch(condition)` は検索を開始し、同じ結果を返す。`clearFaceSearch()` で解除する。
呼出元が `<output id="dice-search-notice" class="DiceSearchSummary"></output>` を用意すると、同IDへ通知を自動描画する。
表示位置は呼出元のHTML/CSSで決める。要素がない場合も検索とダイス上の表示は実行できる。
固定通知とダイス上の表示は同じ表示期限を使い、3秒で両方を消す。同じ条件の再指定では期限を更新する。
両方へ同じ透明度を毎フレーム適用し、フェードイン・フェードアウトを同期する。再指定時は透明度0から再開する。
結果データは期限後も `scene.faceSearch.result` から取得できるが、通知は出し直さない。
一致するダイスの本体に条件アイコンと「×面数」を約3秒重ねる。0面には表示せず、分母も付けない。
表示位置は毎フレーム本体へ追従し、検索通知を通常の結果表示より手前に描く。
条件アイコンは画材記号、色だけの場合は色文字入りのひし形。数値と乗算記号も共通の図形で描く。

ゲーム本体ではカードの目標アイコンから検索する。該当なしの固定層中央表示は後述の「カード目標からの面検索」に従う。

通知は共通 `GameWorksOAK/src/lib/core/i18n.js` のアクティブ言語と `lang-store` 展開を利用する。
日本語・英語の0件・単数・複数の文言と条件名を `searchMessages.js` で管理し、未対応言語は共通規約に従って英語へフォールバックする。
条件アイコンと件数の挿入位置も翻訳文が指定する。文字列はDOMのテキストノードとして挿入する。
表示中の言語変更は通知と読み上げ用の条件名へ反映し、3秒の期限は延長しない。期限後に言語を変えても通知を再表示しない。
シーン破棄時には通知を消去し、言語変更の購読を解除する。

## 共通UIスタイルとの関係

本番ビルドはゲーム用index.htmlと開発者用dev.htmlを両方出力する。Three.jsのcoreとrenderer、cannon-esの物理処理を独立したチャンクとして共有し、500 kBの警告しきい値は変更しない。scripts/checkProductionStartup.cjsで本番配信時のゲーム開始・物理ロールと開発者向けアイコン画面を検証し、開始待ちで初回ロール可能になるまでの時間と取得したJavaScriptの容量を記録する。

配色・共通質感・共通形状の契約は [ゲーム共通UIスタイル](11.shared_ui_style.md) を参照する。
ダイス専用の色変数やtextureクラスは定義せず、共通の用途に従って利用する。
`src/dice/layout.css` と `states.css` はダイス固有の配置・動作・状態を担当する。

## パレットのロールフィールド

`public/assets/field/palette.png` は提供画像（2172×724、透過PNG）をそのまま保持する。
画像は幅26の平面に置き、元画像に含まれる遠近表現がカメラで二重に縮まないよう奥行きを補正する。
床画像は照明による色変化を加えず、別の透明平面でダイスの影を受ける。
`field.js` の同じ多角形から物理壁、生成・位置指定・投げ直し・ロール中の移動制限を求める。
周囲の絵の具は利用可能。左の穴と切欠き、および外縁は利用しない。
回転中の辺長2のダイスもはみ出さないよう、中心は境界から1.8単位内側へ収める。
境界の計算値は共有・キャッシュし、補正が不要なら反復を終了する。
背景画像・影の描画資源はSceneのdispose時に解放する。物理壁と床はGroupが所有する。

## 描画座標の通知

`scene.getScreenPositions()` は各ダイスの `{id, x, y, consumed}` を返す。
x/yはコンテナ左上を原点としたCSSピクセルで、本体中心よりYを0.35下げた点の投影位置。
`scene.subscribeScreenPositions(listener)` は登録直後と各フレーム描画後に一覧を通知し、解除関数を返す。
削除したダイスは一覧から外れる。dispose時は空配列を通知して購読を解放する。
確認ページ・ゲームともIDラベル表示には使用しない。任意の位置追従UIで利用できる。
位置通知の購読解除は利用側が所有する。

準備高さはpose.jsのREADY_HEIGHT=4.5に集約する。prepareは速度・角速度・力・トルクをゼロにし、静的ボディへ戻して空中で姿勢を更新する。確認ページが高さを補正する必要はない。

### v0.16.0 パレット確認の修正

パレットの標準寸法は仮設定600×200を廃し、`paletteLayout.js`で投影寸法から算出する。ワールド1単位を20論理px（辺長2のダイスが40論理px）、周囲の余白を8とし、幅はceil(26×20＋16)=536、高さはパレット全体と、移動可能範囲内で準備高さ4.5にあるダイスの回転頂点が収まる投影範囲から232とする。中心の最奥位置はfieldCenterVerticesで実際の移動範囲から算出し、本体の回転外接半径√3を加える。物理ロールの投入高さ・上向き速度・追加安全余白は含めない。カメラ位置と奥行き補正係数はfield.jsの共通定数を参照する。

ゲームのDiceSceneはbottomAlignedを有効にし、渡された論理幅・高さを20で割った正投影範囲を使う。横方向は中央、下端はパレット手前端の投影位置から余白8で固定する。余分な論理高さは全て上へ追加し、従来の縦横比によるカメラの追加縮小・中央配置を行わない。Canvas自体は描画矩形全体を使用するため、ロール中の上昇やフロートアイコンに上側の空間を利用できる。領域を超える高さではクリップが残り得る。独立サンプルの既定カメラ動作は維持する。

ゲーム本体のパレット表示は`src/game/palettePresentation.js`が所有する。「今日の仕事を始める」を押してからドローと予約効果を解決し、全ダイスを自動で物理ロールする。獲得時・リロール時も準備完了後に自動で振り、全対象の確定結果をGameへ渡して後続処理を再開する。タップ選択とリロールを実装し、長押しによる詳細表示は後続とする。

パレットは手札と同じ下部オフセット(0, 40)を通知する。固定倍率層の`PaletteFixedActions`は高さ36・文字24px/32px、下余白4とし、3D表示はその領域を除いた描画矩形に収める。「使用する画材を決める」は廃止し、ロール要求中は通常のボタンを表示しない。失敗時だけ「ロールを再試行」を表示する。

固定倍率層の左上(0, 0)には、リロール権が1個以上のときだけ既存のリロール権アイコンと「×N」を表示する。上部オフセットは0のままとし、描画領域を狭めず重ねる。アイコンは共通render.jsのrerollTicketCanvas（既存ticket記号）を48×48、個数は24px/32px、間隔4で配置する。表示は入力を透過し、0個では非表示。Gameのrerolls変更と同期し、情報エリアの既存表示も維持する。

ゲーム進行にボタン操作が必要な開始待ち・即時リロールの選択待ちでは、対応するボタンに共通の`state-attention`を付ける。対象未選択でdisabledの場合も拡縮を続ける。自動ロール中はボタン操作を待たないため注目状態を使わない。動きの仕様は[ゲーム共通UIスタイル](11.shared_ui_style.md)に従う。

ターン開始・獲得・権利リロール・効果リロールは共通のrollDice generatorで停止する。獲得は候補選択を終えた新規ダイスだけ、リロールは対象決定後の対象だけを空中待機させる。全物理結果の確定後に同じ効果generatorを再開する。予約効果による獲得も獲得ロールを行い、それらの解決後にターン開始の全体ロールへ進む。

rollRequestがないときは「すべての画材を更新する」「1つの画材を更新する」を横並びで表示する。全体は制作中・選択や演出の待ちなし・権利あり・未使用ダイスありで有効。単体はさらに未使用ダイス1個だけの選択が必要。操作時に権利を1つ消費し、それぞれ全未使用／選択した未使用ダイスを準備後に自動で振る。効果リロールでは権利を消費しない。失敗後の再試行にも追加消費はない。

即時リロールの対象選択中は例外として、パレットの固定ボタンを「選択して画材を更新する」1つへ切り替え、state-attentionを付ける。pending.effectType=rerollで識別し、プレイヤー向けの対象選択ダイアログは生成しない。既存のタップ選択と輪郭表示を使って未使用ダイスを任意の1個以上選び、0個では確定ボタンを無効にする。他の進行操作は停止し、確定後は対象だけのロール準備へ移る。物理結果の全件確定後に後続を再開する。権利は不要で、他の効果の選択ダイアログと評価用画面は維持する。

ボタン領域は高さ36・下部オフセット40のまま維持し、画面幅による2段化や領域拡張は行わない。狭い画面はオーナーが予定する固定倍率調整で対応する前提。

Gameの`manualRolls`はプレイヤー向けセッションで有効。`state.rollRequest`に要求ID・対象ID・ready/rolling状態を保持する。`beginRoll`で開始し、`completeRoll`で全IDの重複なし・確定済み・面番号0〜5を検証して一括反映する。未確定のcurrentはnullとし、達成可能表示・後続操作を先行させない。失敗時は`failRoll`で空中待機へ戻り、再操作できる。評価用ゲームは従来の同期抽選を維持する。予約効果をロール前に解決する順序はオーナーの明示指示による。

物理ロール後の表示同期では確定済みの姿勢を維持し、指定面へ姿勢を置換しない。旧セッションのロール完了は世代番号で無効化する。

他エリアを含む通常の画面更新ではパレットのviewport・結果DOMを接続したまま維持する。共通clearでパレットホストを空にしたり、presentで同じviewportを再appendしたりしない。これにより、先に確定したダイスの出現アニメーションが全結果の確定時に再開されることを防ぐ。再プレイ・終了時のreset/disposeでは従来どおり描画資源を解放する。

### カード目標からの面検索

ゲーム画面のカード目標アイコンをタップすると、指定された画材のみ・色のみ・画材と色の組合せでパレットの全ダイスの面構成を検索する。評価画面と同じFaceSearchと面数バッジを再利用し、該当する各ダイスに面数を表示する。ロール中・ロール待機中・使用済みも検索対象とし、現在の出目・選択・使用状態・ゲーム進行は変更しない。目標タップではカード拡大を開かない。

該当するダイスがない場合だけ、パレット固定倍率層の中央に「（条件アイコン）を含む画材ダイスはありません」を表示する。余白オフセットは増やさない。面数と通知は評価画面と同じ3秒間の一時表示とし、再検索で更新・延長する。評価画面の既存通知文言は維持する。

### パレットのドラッグ移動

停止状態からのロール待機ではprepare({animated:true})を使う。0.3秒でフロートアイコンを現在の表示位置から本体中心へ縮小・吸収し、その後0.5秒で停止高さからREADY_HEIGHT=4.5へ滑らかに上昇させる。同時に回転速度を立ち上げ、元の姿勢から連続した回転を継続する。既に4.5より高い位置で停止していた場合は、その高さを下げない。移行中もGameはロール待機を維持し、準備完了後に表示側が自動ロールを開始する。DiceGroupも未完了の対象ロールを拒否する。

readyMotionは物理描画ループのdeltaで進め、独立したタイマーを残さない。通常再描画で初期化せず、対象外ダイスは維持する。移行中のドラッグはX/Zのみ更新し、上昇中の高さを巻き戻さない。動きを減らす設定では帰還・上昇演出を省略する。独立サンプルのprepare()は従来どおり即時準備だが、準備高さは4.5に統一する。

ゲームのDiceSceneは`draggable: true`で初期化する。共通の`drag.js`がPointer Eventsとポインタキャプチャを使い、本体は3Dレイキャスト、フロートアイコンは対応する結果DOMから対象を特定する。マウスとタッチに対応し、DOM上のIDは識別用属性だけで画面には描かない。

ロール待機中の空中ダイスと確定済みダイスは移動可能。消費済みも本体から移動できる。group.rollingがtrueの間は全ダイスを移動不可とし、先に停止したダイスも例外にしない。ロール開始時・pointercancel・キャプチャ喪失・disposeでドラッグを終了する。

ポインタのビューポート座標を現在のCanvas表示矩形とカメラからワールド平面へ変換する。掴んだ位置のオフセットとダイスの高さを保ち、X/Zだけ更新する。既存のパレット境界補正を通し、穴と外縁を避ける。出目・面構成・姿勢・使用状態は移動では変更しない。ゲーム再描画でも位置を保持する。

移動先の重なりは`dragPosition.js`で判定する。現在の向きの立方体8頂点からXZ平面の凸包を作り、他ダイスの本体との重なりを分離軸で調べる。重なる候補は採用せず直前位置を維持する。境界補正後の候補で判定し、移動途中のすり抜けはオーナー指示どおり許可する。物理ロール中の衝突処理は変更しない。

検証：`node --test tests/implementation/dice/drag.test.js`、`node scripts/checkDiceDrag.cjs <ゲームURL>`。後者は本体・アイコン・空中待機・全体ロールロック・パレット範囲・A/B・タッチ操作・出目保持を確認する。

### タップ選択と達成

達成演出中は判定上の消費と表示を分離する。palettePresentationのheld集合に使用IDを保持し、そのIDの表示だけは吸収完了まで未消費の外観を維持する。飛行中は元の結果をtravelling集合で隠し、共通移動層へ複製を表示する。各アイコンの帰還吸収が終わった時点で対応する表示を消費済みにする。演出中のドラッグをロックし、終了・中断時にheld・travelling・ロック・移動複製を解放する。Gameのused状態を戻したり、ルールを表示側で再判定したりしない。演出順序は[プレイエリア](15.play_area.md#着手と達成の演出)を参照する。

本体・フロートアイコンの短いタップで選択／解除する。pointerdownから550ms未満、移動量6 CSS px未満をタップとし、一度でも6px以上動かした操作は、元の位置へ戻しても選択を切り替えない。pointercancel・キャプチャ喪失も選択しない。長押しは情報表示用として予約し、今回は情報を開かず選択も変更しない。

Gameの制作中で未使用・確定済みのダイスだけを達成用に選択できる。ロール待機・ロール中・効果選択・達成演出・仕事終了後は新たに選択できない。移動可否は従来どおり別に扱い、待機中と消費済みもドラッグは可能。

選択の正本はview.jsの既存selected集合。パレットからのタップで同じ集合を更新し、既存のsatisfiesSelectionによる達成ボタンの有効・無効を即時更新する。達成ではそのID集合をGameへ渡して消費し、選択を解除する。描画側へルール判定を複製しない。

DiceScene.setSelectedで本体に輪郭用の背面メッシュ、フロートアイコンにstate-selectedの輪郭を表示する。色は既存の--ui-selected-borderを共有し、面内容や結果姿勢を変えない。選択表示は通常再描画・リサイズでも保持し、消費・未確定・ロール中は表示しない。長押し情報ボタンやダイアログは追加しない。

本体輪郭は床の深度で下端が切れないよう、ステンシルを利用する。全ダイスの可視面をステンシルへ記録し、床より後に輪郭を描くときはダイスの面を除外する。輪郭自体は深度テスト・深度書込みを無効にし、接地部分を含めた外周を表示する。面の絵柄を輪郭色で覆わず、他ダイスの可視面も保護する。

検証：`scripts/checkDiceSelection.cjs`は本体・アイコンでの選択解除、縁取り、余分な選択での達成不可と解除後の復帰、長押し／ドラッグで選択しないこと、リサイズ後の保持、選択ダイスの達成消費を検証する。検証用設定とセッション参照は検証ページ内だけで保持し、本番APIや保存済み設定は変更しない。

DiceSceneの第5引数は省略可能な`{ transparent, readSize }`。ゲームでは透過背景と、エリアの論理幅・高さ・エリア倍率を含むpixelRatioを渡す。共通のDOM座標変換による倍率は親へ一度だけ適用する。サンプルは従来どおり表示寸法から描画する。状態更新では同じシーンを再利用し、ゲーム終了・再プレイでは解放する。

パレット画像は元の2172×724と透過を保ち、asset自体を左右反転して保存した。描画時の反転は行わない。境界多角形と初期配置も画像に合わせて左右を反転した。ダイス本体と物理形状は従来の2倍とし、結果表示の倍率と本体上面へのアンカーも追従させる。
