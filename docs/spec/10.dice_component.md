# ダイスコンポーネント

## 目的と入口

ゲーム進行から独立した3Dダイス単体・群と、その確認画面を提供する。
既存の `src/game/dice.js` による抽選や効果処理は置き換えない。
起動方法は `npm.cmd run dev`。入口の「ダイス動作確認を開く」、または `/#dice` を開く。
設定データを読み込まずにダイス画面を起動できる。
確認バージョンは共通Env Utility経由で画面右上へ表示する。

## 構成と所有

| モジュール | 責務 |
| --- | --- |
| `src/dice/Die.js` | 6面、ID、所持期間、状態、単体の物理ボディ・結果 |
| `src/dice/DiceGroup.js` | ダイス管理、共有物理空間、複数ロールの完了管理 |
| `src/dice/orientation.js` | ローカル面法線からワールド上面を判定 |
| `src/dice/geometry.js` | 稜・頂点を丸めた描画用ダイス形状 |
| `src/dice/specialFrameLayout.js` | 特殊面を示す星型フレームの形状と配置 |
| `src/dice/faceConditions.js` / `FaceSearch.js` | 面の一致判定と検索表示の期限管理 |
| `src/dice/searchIcons.js` | 条件アイコンと一致面数の図形描画 |
| `src/dice/FaceSearchNotice.js` / `searchMessages.js` | 固定IDの検索通知と共通i18nによる文言・条件名の翻訳 |
| `src/dice/icons.js` | 通常面の記号・色文字、特殊面の共通図形と効果アイコン |
| `src/dice/glyphs.js` | フォント非依存の色文字・数字・符号・矢印 |
| `src/dice/laurel.js` | 円形の月桂冠と汎用の名声数値表示 |
| `src/dice/resultGraphics.js` | 既存画像の読込み、着色合成、結果画像キャッシュ |
| `src/dice/colorizeGrayscale.js` | 元のアルファと明暗を維持し、指定色の色相・彩度で着色する |
| `src/dice/DiceScene.js` | 3D表示、実行ループ、リサイズ、結果表示、描画資源解放 |
| `src/dice/lab.js` | 同じ単体・群クラスを使用する動作確認画面 |

描画はThree.js、物理はcannon-esを使用する。両者は同じ右手系・Y上向きを使用でき、
ボディの位置とクォータニオンをそのまま描画へ反映できるため採用する。
各依存のバージョンはpackage.json、再現可能な解決結果はpackage-lock.jsonで管理する。
公式資料: [Three.js BoxGeometry](https://threejs.org/docs/pages/BoxGeometry.html)、
[WebGLRenderer](https://threejs.org/docs/pages/WebGLRenderer)、
[cannon-es World](https://pmndrs.github.io/cannon-es/docs/classes/World.html)。

群は物理Worldと床・境界・各ダイスを所有する。
シーンはRAF、ResizeObserver、WebGLRenderer、ジオメトリ、面テクスチャ、マテリアル、
照明、結果DOM、画像キャッシュを所有する。画面終了・pagehideでシーンを破棄し、群も破棄する。
ダイス削除時は次フレームで対応するメッシュ・テクスチャ・結果DOMを解放する。

## 単体API

`new Die({ id, faces, lifetime, position })` で生成する。
群に追加する場合は `group.add(options)` を使用する。
IDは空でない文字列、facesは6要素。面は `{ color, material }` または `{ special }`。
識別子と特殊面は既存の `effectCatalog.js` を正本とする。
面データはコピーして凍結し、外部からの書換えを避ける。
所持期間は `permanent` / `temporary`。生成後の変更は対象外とする。

| API | 契約 |
| --- | --- |
| `id`, `faces`, `lifetime`, `state`, `consumed` | 状態参照。変更は対応するメソッドを使用 |
| `setFace(index, face)` | 0〜5の面を変更。確定中の現在面なら結果にも反映 |
| `findFaces(condition)` | 6面のうち条件に一致する面のindex配列を返す。状態は変更しない |
| `setPosition({x,y,z})` | 有限数のワールド座標へ移動。群所属時はパレットの有効範囲内へ補正。結果表示も追従 |
| `prepare()` | 以前の結果を破棄し、ロール前の空中回転状態へ戻す |
| `setConsumed(boolean)` | 所持したまま消費状態を変更。ロール対象にできなくする |
| `roll()` | 所属群の単体対象ロールへ委譲し、単体結果のPromiseを返す |
| `result` | 確定中だけ結果を返す。それ以外はnull |
| `top` | 現在の姿勢における上面indexと上向きの一致度 |
| `dispose()` | 待機中の単体結果を中止で解決し、所属群・物理空間から除去 |

`begin`、`settle`、`cancel`、`body`、`owner`は群・描画との内部接続用。
結果は `{id, status:'settled', index, face, lifetime}`。
削除・破棄時は `{id, status:'cancelled'}`、停止に失敗した場合は `{id, status:'failed'}`。
物理的に確定していない面を結果として返さない。
単体の確定通知は内部の `pending` Promiseの解決で行い、群全体の確定を待たない。

## 群API

`new DiceGroup({ random = Math.random })`。乱数はロールの初期姿勢・速度と初期配置だけに使用する。
ゲームのルール判定、獲得・消費の自動処理、特殊面の効果発動は行わない。

| API | 契約 |
| --- | --- |
| `add(options)` | 単体を生成・所有して返す。ID重複を拒否。最大12個 |
| `remove(id)` | ID指定で削除。ロール中も可。結果待機は中止で解決 |
| `get(id)` / `dice` | 単体参照 / 追加順の単体配列 |
| `findFaces(condition)` | 一致するダイスだけの `{id, indices, count}` 配列を追加順に返す |
| `roll(ids?)` | 指定IDを同時ロール。省略時は未消費の全ダイス |
| `rolling` | 群のロール完了待ち中かどうか |
| `step(deltaSeconds)` | 描画ループ等から物理と待機姿勢を進める |
| `dispose()` | 全待機を中止で解決、全ダイス・床・境界を解放。重複呼出し可 |

`roll` は指定順の結果配列をPromiseで返し、全対象が確定・中止・失敗した後に解決する。
選択状態と入力方法は呼出元のUIが管理する。群には選択したID配列を渡す。
確認画面はチェックボックスで選択する。3Dのダイス本体へのクリック・タップと、選択中の外観表示は未実装。
対象外の確定結果と姿勢は保持する。対象外がロール前なら空中回転は継続する。
空対象、重複ID、不明ID、消費済み対象を拒否する。全対象を検証してから開始するため、
一部だけ開始されることはない。群の同時ロール中の別ロール・追加は拒否する。
破棄後の追加・ロールも拒否する。

## 状態と停止判定

| 状態 | 表示と遷移 |
| --- | --- |
| ready | 結果なし。空中でX/Y/Z軸を異なる速度で回転。rollでrollingへ |
| rolling | 結果なし。共有Worldで衝突・落下・回転。停止でsettledへ |
| settled | 上面を保持して結果が出現・浮遊。再ロール開始時に以前の結果を消す |
| disposed | 非表示・群から除去。再利用不可 |

ロール中の面変更・prepare・移動・消費切替は拒否する。
結果の出現・浮遊は確定状態に付随する描画であり、群の完了を遅延させない。
消費は状態とは別属性。ダイス本体を暗くし、浮遊する結果（画材・特殊面）を非表示にする。未消費に戻すと保存された結果を再表示する。
破棄は本体・結果を除去するため、消費と区別できる。確認ページのIDラベルも所有するダイスが削除されたら除去する。

辺長1の剛体箱を使用する。重力はY=-18、床はY=0。境界はfield.jsに定義したパレット内側の凸多角形。
摩擦0.45、反発0.28。固定刻み1/120秒、最大6サブステップ、フレーム差分は最大0.05秒。
バックグラウンドからの復帰時に大きな差分を一度に投入しない。
各ダイス間と床・壁との衝突を同じWorldで処理する。
ロール対象だけ動的ボディにし、対象外は静的ボディとして位置・出目を保持する。

線速度・角速度がともに0.13未満で0.5秒継続し、上面一致度が0.99超、中心Yが0.8未満なら確定。
上面は6法線をクォータニオンで回転し、ワールドY成分が最大の面とする。
BoxGeometryのマテリアル順に `+X,-X,+Y,-Y,+Z,-Z` が `index=0,1,2,3,4,5` に対応する。
表示する面番号はindex+1。姿勢を別の出目に置き換える処理は行わない。
傾いた静止・積み重なりは0.8秒の低速状態、長時間の未停止は12秒で検出して再投入する。
再投入は最大3回。なお停止できなければfailedとして再操作可能に戻し、確認画面に案内する。

## 通常面と特殊面

中央の画材記号は絵筆=しずく、パステル=角丸平行四辺形、エアブラシ=同径の3円を重ねた塗り形状。
エアブラシの円周・重なり線は表示せず、一時では白い形状の外周だけに色の縁取りを付ける。
文字中心は記号座標で絵筆Y=62、パステルY=51、エアブラシY=47。
色文字は橙O・黄Y・緑G・青B・紫P・赤R。
アイコン内の色文字・数字0〜9・符号・左向き矢印は `src/dice/glyphs.js` の共通パスで描き、インストール済みフォントへ依存させない。
色文字は閉じた太い輪郭を塗りつぶして描き、通常面と特殊面で字形を共有する。6色すべてに共通の暗い縁取りを付ける。
永続は色付き記号と白文字、一時は白い記号に色の縁・色文字。
黄色は#dbb61eを基本とする。最終的な見やすさはオーナー検証で判断する。
面画像は256pxのCanvasTextureで、背景は四隅まで不透明に塗る。確認一覧は同じ描画関数から生成する。
描画形状は辺長1・丸み半径0.14・分割数4のRoundedBoxGeometryとし、中央の平面を残して稜・頂点を丸める。
6マテリアルの順序は上面判定と共通。物理形状は辺長1の箱を使用する。

特殊面は `SPECIAL_FACES` / `SPECIAL_FACE_EFFECTS` の10種類。
名声は月桂冠と+1、ドローは手札・左向き矢印と+1、リロール権はチケット内に傾いた六角形・Y字と波紋。
月桂冠は半径36の真円弧に沿う茎と葉で構成する。汎用の `drawFameIcon(ctx, amount)` は非ゼロの安全な整数を受け、
白縁の数値をサイズ30で描く。+10も同じ大きさとし、幅70を超える場合だけ縦横比を保って縮める。減少値は赤色。
ドローの `drawCardDrawIcon(ctx, count)` は正の安全な整数を受ける。想定表示は1桁で、数値サイズは23固定。
3枚の手札を下端の共通支点から左右へ開き、右側に白縁の左向き矢印と数値を中心X=77で縦に揃える。
チケットは金色#f2ce79の横長形状に、半径3の上下の切欠きと半券の切り取り線を付ける。
中のダイスは白く塗り、右上の頂点へ向かう方向に半径6・10の波紋を置く。
一時ダイス獲得は六角形に、通常=Y字、補色=2色領域と各色文字、画材指定=共通画材記号を入れ、
左右に雲状の補助記号を付ける。×1は省略。発動タイミングと星型は含めない。
特殊面の結果表示は淡い金色の星型フレーム（共通texture-highlight-frame）とし、共通効果アイコンを透過画像として中央に置く。ダイスを指す尾は付けない。星は外半径48・内半径25の5つの先端を持ち、アイコン領域は中央の50%角とする。フレームは80〜144pxで表示し、形状の視認性と内側のアイコン領域を両立する調整案として確認する。
ダイス上面の投影位置の上方へ配置し、画面端では内側に収める。フレームの形はダイスとの位置関係で変えない。
星型フレームと画材は同じ描画構造・アニメーションを使う。
0.7秒かけて45px下・倍率0.45・透明の状態から出現し、その後3秒周期・7px幅の上下動と左右±3度の回転で浮遊させる。
星型フレームと内側のアイコンを一体で動かす。

## 結果画像と配置

`public/assets/dice/*_grayscale.png` は明暗をRGB、透過を別のアルファチャンネルに保持する。
グレーの明暗をHSLの明度に使い、出目の色から色相・彩度を与える。元のアルファ値は変更しない。
その上に同位置・同サイズの `*_fixed.png` をsource-overで合成する。
固定部分の色、画材本体の不透明さ、元画像の陰影・ハイライト・透過を保持し、元の画像ファイルは変更しない。
3画材の6画像を事前読込みし、生成結果を面データ単位でキャッシュする。
画像読み込み失敗はメッセージと再読込み・入口の操作を表示する。

結果は0.7秒でダイス付近から出現し、3秒周期で7px上下動する。
再ロール・prepare時に非表示、面変更時に画像を再生成する。
結果位置は毎フレーム、ダイスのワールド位置をカメラでスクリーン座標へ投影する。
画材画像の下端を本体上面の投影位置から4px上へ合わせ、幅はダイスの描画寸法の約2倍に合わせて64〜144pxで調整する。
画面端のはみ出しだけを補正し、重なり回避を理由に本体から遠くへ移動させない。
確認用IDはlab/IdOverlay.jsが確認ページだけで作り、本体付近へ重ねる。共通DiceSceneはIDラベルを生成しない。浮遊する結果画像にもIDを付けない。
結果画像の重なり順はダイス中心を投影した画面Y座標の昇順とし、画面下側のダイスに対応する結果を手前に描く。位置の変化に合わせて毎フレーム更新する。
縮小表示は画面全体のCSS scaleで行わず、カメラの表示範囲とレイアウトで対応する。

カメラは正投影、位置(0,15,9)、原点を見る。
半球光・影付き平行光を使用し、床には提供された透過パレット画像を使用する。
ダイスの面背景は永続がアイボリー（#fffaf0）、一時が明るい水色（#98d5ed）。一時の記号内部は白を保つ。
照明下でも所持期間を区別できる明度差を設ける。
初期配置は4列×3行、X間隔2.3・Z間隔2.2、位置に±0.09の揺らぎ。
ロール前は3軸回転、ロール後は物理姿勢が回転・配置の揺らぎになる。

## 確認画面の操作

- 対象は「未消費の全体」「選択した複数」「編集中の単体」から選ぶ。
- 「使う画材を決める」で同時ロール。「対象を空中回転へ戻す」で結果を消して準備状態にする。
- 一覧のチェックで複数対象を選ぶ。「編集」で対象の6面を開く。
- 各面の種類・色・画材を変更する。確定した面の編集は、上面と結果にも反映する。
- 追加欄で画材または特殊面と所持期間を指定する。画材なら6色各1面、特殊面なら6面すべて同じ効果。
- 「このダイスを削除」はロール中も操作可能。「消費済みにする」は対象から外して外観を変える。
- 下部の比較欄は通常面18組×所持期間2種、特殊面10種を同じ描画部品で表示する。
- 横長は操作部を右、縦長は下へ配置する。操作部と比較欄だけ内部スクロールする。
- WebGLが利用できない場合は開始失敗と再読込みを表示する。

## 面構成の条件検索

条件は `{material}`、`{color}`、`{material,color}` のいずれか。識別子は既存カタログを使用する。
空条件・未知のキーや識別子は拒否する。画材＋色は同じ面が両条件を満たす場合だけ一致する。
特殊面は通常の画材・色検索に一致させない。現在の出目に関係なく6面を調べ、同じ面定義の重複もそれぞれ数える。
所持期間・消費状態では除外せず、対象選択・出目・姿勢・位置を変更しない。

`FaceSearch` は条件と表示期限を持つ。`search(condition)` の戻り値と `result` は
`{condition,hits,diceCount}`。`active` は3秒間だけtrue。同じ条件で再実行しても期限を更新する。
`result` は最新の面構成・所持ダイスで計算し、期限後も保持する。`clear()` で条件と期限を解除する。
`opacity` は同じ時計で計算し、開始から200msで0→1、終了前300msで1→0となる。

`DiceScene.showFaceSearch(condition)` は検索を開始し、同じ結果を返す。`clearFaceSearch()` で解除する。
呼出元が `<output id="dice-search-notice" class="DiceSearchSummary"></output>` を用意すると、同IDへ通知を自動描画する。
表示位置は呼出元のHTML/CSSで決める。要素がない場合も検索とダイス上の表示は実行できる。
固定通知とダイス上の表示は同じ表示期限を使い、3秒で両方を消す。同じ条件の再指定では期限を更新する。
両方へ同じ透明度を毎フレーム適用し、フェードイン・フェードアウトを同期する。再指定時は透明度0から再開する。
結果データは期限後も `scene.faceSearch.result` から取得できるが、通知は出し直さない。
一致するダイスの本体に条件アイコンと「×面数」を約3秒重ねる。0面には表示せず、分母も付けない。
表示位置は毎フレーム本体へ追従し、検索通知を通常の結果表示より手前に描く。
条件アイコンは画材記号、色だけの場合は色文字入りのひし形。数値と乗算記号も共通の図形で描く。

確認画面の「面構成を探す」で条件種別・画材・色を指定し、「条件を含むダイスを探す」を押す。
描画領域の上の固定欄に「[条件アイコン] を含むダイスがN個あります」、0件なら
「[条件アイコン] を含むダイスはありません」を3秒間表示する。
通知の表示中は面変更・追加・削除によって件数を更新する。入力欄の変更だけでは検索条件を切り替えず、ボタンで確定する。
「検索表示をクリア」で通知と重ね表示を解除する。
確認画面では通知が消えても領域の高さを保ち、ダイス表示のリサイズや位置の飛びを防ぐ。

通知は共通 `GameWorksOAK/src/lib/core/i18n.js` のアクティブ言語と `lang-store` 展開を利用する。
日本語・英語の0件・単数・複数の文言と条件名を `searchMessages.js` で管理し、未対応言語は共通規約に従って英語へフォールバックする。
条件アイコンと件数の挿入位置も翻訳文が指定する。文字列はDOMのテキストノードとして挿入する。
表示中の言語変更は通知と読み上げ用の条件名へ反映し、3秒の期限は延長しない。期限後に言語を変えても通知を再表示しない。
シーン破棄時には通知を消去し、言語変更の購読を解除する。

## 共通UIスタイルとの関係

配色・共通質感・共通形状の契約は [ゲーム共通UIスタイル](11.shared_ui_style.md) を参照する。
ダイス専用の色変数やtextureクラスは定義せず、共通の用途に従って利用する。
`src/dice/layout.css` と `states.css` はダイス固有の配置・動作・状態を担当する。

## パレットのロールフィールド

`public/assets/field/palette.png` は提供画像（2172×724、透過PNG）をそのまま保持する。
画像は幅26の平面に置き、元画像に含まれる遠近表現がカメラで二重に縮まないよう奥行きを補正する。
床画像は照明による色変化を加えず、別の透明平面でダイスの影を受ける。
`field.js` の同じ多角形から物理壁、生成・位置指定・投げ直し・ロール中の移動制限を求める。
周囲の絵の具は利用可能。左の穴と切欠き、および外縁は利用しない。
回転中の辺長1のダイスもはみ出さないよう、中心は境界から0.9単位内側へ収める。
境界の計算値は共有・キャッシュし、補正が不要なら反復を終了する。
背景画像・影の描画資源はSceneのdispose時に解放する。物理壁と床はGroupが所有する。

## 描画座標の通知

`scene.getScreenPositions()` は各ダイスの `{id, x, y, consumed}` を返す。
x/yはコンテナ左上を原点としたCSSピクセルで、本体中心よりYを0.35下げた点の投影位置。
`scene.subscribeScreenPositions(listener)` は登録直後と各フレーム描画後に一覧を通知し、解除関数を返す。
削除したダイスは一覧から外れる。dispose時は空配列を通知して購読を解放する。
確認ページはこれを使いIDラベルを表示する。ゲームは任意のUIへ使えるが、IDを描画する義務はない。
確認用のID表示DOM・CSS・購読解除はlab側が所有する。
