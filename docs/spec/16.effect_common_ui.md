# 効果の共通通知と説明

## 対象と責務

ゲームで使う効果の分類は `effectCatalog.js` の16種類を維持する。効果処理は `game/effects.js`、開発者向け一覧・ログは `cardSummary.js` が担当する。

ユーザー向け説明は `game/effectDescriptions.js` を定義元とし、`game/cardMessages.js` を通じて既存i18nで日本語・英語へ展開する。通知・カードの説明・特殊面の説明は同じ定義を参照する。

## 本文の契約

- 基本的に数量を表示しない。「3個の候補」「1個以上」は操作条件として表示する。
- 永続／一時、補色、画材、色、変更先ステップは設定に応じて置換する。名声は増加／減少で文を分ける。
- 数量不足・対象なしでも本文を変更しない。本文は効果内容を説明するもので、実績値の報告ではない。
- 通知専用の時制へ切り替えず、処理順・不足時・所持期間等の補足を自動で追加しない。
- 特殊面の説明を別定義にしない。`SPECIAL_FACE_EFFECTS` が示す効果を共通生成経路へ渡す。

| 効果 | 日本語本文 |
| --- | --- |
| refreshDice | 使用済みのダイスをすべて未使用に戻す。 |
| gainNormalDice | {期間}ダイスを3個の候補から選んで獲得する。 |
| gainColorDice | {補色}の{期間}ダイスを獲得する。 |
| gainMaterialDice | {画材}の{期間}ダイスを獲得する。 |
| gainRerolls | リロール権を獲得する。 |
| reroll | 1個以上の未使用ダイスを選択して振りなおす。 |
| changeColor | 未使用ダイスを選択し、現在の面の色を{色}に変更する。 |
| changeMaterial | 未使用ダイスを選択し、現在の面の画材を{画材}に変更する。 |
| changeSpecialFace | 未使用ダイスを選択し、現在の面を［特殊面アイコン］に変更する。 |
| discardDice | 未使用ダイスを選択して破棄する。 |
| changeFame | 名声値を増やす。／名声値を減らす。 |
| drawCards | デッキからカードを引いて手札に加える。 |
| gainStockCards | ストックの公開カードを選択して捨て札に加える。 |
| changeCardStep | 手札のカードを選択し、ステップを{ステップ値}に変更する。 |
| exchangeCards | 手札のカードを選択し、ステップを0に戻してストックに戻す。その後、ストックの公開カードを選択して手札に加える。 |
| activateSpecialFaces | 未使用ダイスに現在出ている特殊面の効果をすべて得る。 |

`effectParts` は本文を文字列とインライン効果データの配列として返す。特殊面への変更では、インライン効果データを変更先の既存アイコンで表示する。アクセシビリティ用の文字列は同じ効果定義を展開して生成する。

## 表示と操作

`cardIcons.js` の `effectBody` が「効果アイコン＋説明文」の行を生成する。通知は全効果、カード説明は選んだ効果を渡す。

本文行の効果アイコンは縮小せず、元の縦横比と指定高さを維持する。長文は文章側を折り返す。カード内の横並びアイコンを縮小する指定は `CardIconSequence` の子だけへ適用し、通知本文へ適用しない。

- ホバー表示はアイコンから離れると即座に閉じる。
- タップ表示は離れても保持する。本文内の特殊面アイコンをタップすると追加説明を表示する。
- 外側のタップ、元のアイコンの再タップ、Escapeで閉じる。画面再描画・破棄で元アイコンを解放するときも説明を解放する。
- 説明欄の本文内アイコンはタップ表示時だけ操作可能とする。

カード内と本文内の効果アイコンは `iconPopovers.js` の同じ処理を使う。表示元アイコン・ポップアップ・タップによる保持状態を階層ごとに対で管理する。親をタップで開いた後は、本文内のアイコンもホバーで表示し、離れると子の説明だけを閉じる。タップで開いた子の説明は、そのアイコンの再タップまたは子の外側のタップで閉じる。親の中をタップした場合は親を残す。最上位の外側をタップすると全体を閉じる。

## 通知の構造

`paintingBlock.js` でカードと通知の外枠・左の発動契機欄を共用する。左欄は通知ごとに1つ、右の本文だけを効果ごとの複数行にする。

| 契機 | 左欄 | 通知タイミング |
| --- | --- | --- |
| プレイ | 既存のプレイ時アイコン・青系 | 着手演出後 |
| 達成 | 既存の達成時アイコン・緑系 | カード・イーゼル撤去と、ステップ更新・捨て札への移動または出荷の後 |
| 特殊面の即時適用 | ★ | 親の通知後に特殊面効果をまとめて表示 |
| 特殊面の予約 | ★ | ターン終了時の予約時だけ表示 |

予約済み効果の翌日発動時と、通常の日次ドロー・リロール権付与は通知しない。特殊面用の配色は共通の中立色を使用し、正式な配色の判断は別途行う。

枠の上には背景・枠線付きのタイトル「獲得効果」（英語: Gained effects）を置く。画面中央付近に表示し、効果数によらず3秒で消える。通知自体は操作を止めない。確認ボタンは設けない。本文20px、効果アイコン40px、発動契機欄52px、最大幅720px。狭い画面ではビューポート内へ収める。通知に追加の動きは付けず、動きを減らす設定でも同じ本文・時間を維持する。

横幅はタイトルを含む外側のグループで管理する。内側の通知枠はborder-boxで親幅の100%とし、枠線による横方向のはみ出しを防ぐ。本文は折り返す。通知をスクロールして読む操作は設けず、通知にスクロール領域・高さ制限を設けない。

特殊面の通知では、同じ効果を1行にまとめる。種類・補色・画材・所持期間などの設定が一致するものをまとめ、数量・名声増加量はアイコン用データで合算する。本文には数量を追加しない。異なる設定は別行とし、最初に現れた順を維持する。この集約は `specialNoticeEffects.js` で描画用データにだけ適用し、実際の効果処理・予約データ・発動回数は変更しない。プレイ・達成時の元の効果配列は集約しない。

## イベントとライフサイクル

`Game.notifyEffects` は `{id, timing, effects}` を `state.effectNotices` に追加する。効果配列を複製し、ログの文字列解析を行わない。プレイ・達成は全効果を1件へまとめ、特殊面の即時適用は対象確定後に子の効果群を追加する。空配列は通知しない。

`effectNotices.js` は描画時に未受領イベントを取り出し、`effectNoticeQueue.js` へ順序を維持して渡す。キューは演出中に新しい通知を開始せず、演出完了後に開始する。通知の寿命は再描画から独立し、同じイベントを再表示しない。

通知自体はゲーム操作を止めない。解決済みの効果では、次の操作が可能。対象選択・ロール待ちは既存の操作制限を維持し、通知キューが空になってから選択UI・物理ロール表示へ進む。効果の論理処理の順序は変更しない。

通知レイヤーはビューポート基準でbodyへ配置し、ゲームの再描画で破棄しない。再プレイ・入口への移動・画面破棄時は通知キュー・タイマー・通知内アイコンの監視・レイヤーを解放する。

## 検証経路

- `tests/implementation/game/effectNotices.test.js`: キュー、複数発動、破棄、日英本文と特殊面の共用、特殊面予約。
- `scripts/checkEffectCommonUi.cjs`: 本文のホバー／タップ、入れ子、通知寸法、狭い画面、日英、自動消去。
- `scripts/checkEffectGameConnection.cjs`: ゲームへの接続、連続通知、選択再開、予約だけの通知、破棄。
- `scripts/checkAutomaticRolls.cjs`、`scripts/checkAchievementMaterials.cjs`: 既存の物理ロール・達成演出との接続。
