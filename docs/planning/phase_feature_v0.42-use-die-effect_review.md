## R42-01 [P2] 要求03に旧破棄効果の受入条件が残っている

`docs/requirements/03.information_and_interaction.md` §3.13（235・239行）には、依然として「リロール・面変更・破棄」「ダイスN個の破棄効果」「未使用ダイスをすべて破棄すること」が残っている。一方、更新済み要求06 §5および実装は、対象を所持したまま使用済みにする。従って同一効果の受入条件が文書間で矛盾し、現行実装で要求03を満たせない。

要求03の87行にも破棄による達成可能表示更新の記述が残る。要求01の200・218行、要求02の121行にも旧ダイス破棄への言及があるため、同じ影響調査で意味を確認する。単純な一括置換はせず、日末回収や一般的な資源破棄との意味の違いを区別する。

対応: 実装担当は、必要な対象ファイル・節ごとに修正前後の文面または差分をチャットで提示し、オーナーの明示承認後に承認内容だけを反映する。requirementsの変更を先行させない。変更不要と判断する関連記述は、その理由を実装報告へ記録する。

完了条件: 要求03 §3.13を含め、今回の効果について「所持から削除」と「使用済み化」の相反する条件が残らない。要求01〜03の関連言及について判断と対応を記録し、必要な修正への承認を記録する。修正版の全テスト・本番ビルド結果も記録する。
