# v0.41.1 ダイスの低位置確定と再投入時のパレット拡大

## 実装結果とオーナー合意

- 出目の確定は既存の線速度・角速度0.13未満、低速継続0.5秒超、上面一致度0.99超に加え、中心Yが1.2未満で行う。厳密な床接触は要求せず、想定する傾き・小さな浮きを許容する。
- 各ダイスの再投入のたびに、床・外縁・全ダイスのX/Z座標を中心固定で1.03倍に拡大する。高さ・姿勢・出目・使用状態・ダイス本体寸法は維持する。
- 4回ごとの拡大判定用カウントは廃止した。同時に複数ダイスを再投入した場合も、それぞれ拡大する。
- 個数による事前拡大・減少時の縮小、および再投入8回の上限を廃止した。拡大したサイズは同じゲーム中保持する。上限到達に伴う案内・復帰操作は不要となる。例外・キャンセル等の既存エラー経路と再試行UIは維持する。
- パレットの標準寸法は536×232に固定。物理拡大と同倍率でカメラ範囲・余白を広げ、画像の表示位置・寸法と周囲の余白を維持する。ダイスは相対的に小さく見える。
- 自動再投入と拡大はDiceGroup内で処理し、同じロール要求の完了を待つ。追加の権利消費や効果解決は行わない。
- バージョンは最終採用済みの0.41.1。要求仕様・共通リポジトリは変更していない。

## 主な変更箇所

- src/dice/DiceGroup.js: 高さ制限、再投入カウント、フィールド拡大・サイズ保持、拡大通知。
- src/dice/field.js: 個数による倍率計算を削除。配置・再投入スロットと境界制約は現在倍率を使用する。
- src/dice/paletteLayout.js、src/game/palettePresentation.js: 標準寸法を維持し、物理拡大をカメラへ通知する。
- tests/implementation/dice/: 床上と積み重なり、浮いた静止の再投入、再投入ごとの1.03倍拡大、複数対象の個別拡大、8回超継続、状態保持、倍率保持、投影位置・余白維持の検証。
- tests/implementation/game/largePalette.test.js: 各ロール最大300物理秒。個別13/20/30個と同じ倍率を継承する13→20→30個を検証し、確定後の中心高さを実装定数から独立に0.85以上1.2未満で検査する。失敗時は確定直前の傾き・速度・周囲の座標を出力できる。
- scripts/createPaletteExpansionReview.cjs: 初期20個の確認専用ページを生成。A/B幅切替・再開始・拡大回数表示・ページ内だけの動きを減らす条件を提供。生成HTMLはignore対象で本番ビルドに含まれない。
- scripts/checkLargePalette.cjs: 新しい倍率・表示寸法と高さ条件に合わせて更新し、待機を330秒に変更。今回このPlaywrightスクリプト自体は未実行（ローカルにPlaywrightを必須導入せず、画面操作は接続済みブラウザーで確認）。
- docs/spec/10.dice_component.md、14.screen_layout.md、19.palette_operation.md、docs/01.development.mdと計画書を合意内容へ更新。
