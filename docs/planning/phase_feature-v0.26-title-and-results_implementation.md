# v0.26 タイトル画面とゲーム終了後の遷移 実装報告

## 実装結果

- `/MyPalette/` に、アトリエに隣接する展示スペースを描いたタイトル画面を追加した。額装したタイトル専用の絵と名札がメニューとなる。横長では額を横に、縦長では縦に並べ、絵の3:2を保って大きく表示できる側に名札を置く。表示項目を差し替えたときと、画面を伸縮したときに再計算する。
- 現バージョンは「ゲーム開始」の1項目を表示する。記録・ギャラリー・設定は利用できる機能が追加されたときに接続する。
- バージョンは `package.json` をもとに表示する。著作権者、年、ポータル名、URLは `src/appMetadata.js` に定義し、フッターに `© T.I.OAK 2026 | GameWorks OAK` を表示する。
- 「ゲーム開始」で保存済み設定を取得・検証する。読み込み中は重複操作を防ぎ、失敗時は理由と再試行ボタンを表示する。読み込み・エラーの通知はメニューの下の余白に表示し、額と名札の配置を変えない。
- 信用0の日は演出と名声反映が完了してからゲーム表示を破棄し、仮の「ゲーム終了」画面に切り替える。「タイトルへ戻る」からの開始は新しいゲームを生成する。
- 通常入口を使う既存ブラウザー検証にタイトルでの開始操作を追加し、仕様書と開発手順に画面遷移を反映した。

## 検証結果

- `npm.cmd test` で216件成功。サンドボックス内ではローカル接続と一時ファイルの置換が拒否されたため、制限外で再実行した。
- `npm.cmd run build` 成功。
- `node scripts/checkProductionStartup.cjs <プレビューURL>` をEdgeで実行し、タイトル、設定エラーと再試行、レイアウトA/Bでの翌日・終了・再開始、開発者用入口を確認した。設定の取得を保留して横長・縦長ともに読み込み中のボタン・額・名札の位置とサイズを開始前と比較し、エラー表示時も同じ位置とサイズであることを確認した。
- `node scripts/checkTitleMenu.cjs <開発URL>` で同じ画面の表示項目を1→2→3→1件に切り替えた。各件数で横長・縦長の6サイズに変更し、拡大・縮小、絵の3:2、名札の位置、スクロールなし、額と名札のクリック範囲を確認した。
- `node scripts/checkScreenLayout.cjs <開発URL>` で7画面サイズの配置と開発者用2画面を確認した。
- `node scripts/checkIconCleanup.cjs <開発URL>` で終了と再開始を含むカードアイコンの監視を確認した。終了時に監視対象は0件だった。
- `node scripts/checkLayoutLayers.cjs <開発URL>` と `node scripts/checkPaletteArea.cjs <開発URL>` でレイヤー、パレット、画面サイズ変更を確認した。Tabの検証はゲーム内の操作要素を対象にして再実行した。
- `node scripts/checkReadyTransition.cjs <開発URL>` で開始時の操作ロックと振り直しを確認した。
- `node scripts/checkDiceDrag.cjs <開発URL>` では、仕事開始直後のドラッグ禁止のアサーションで失敗した。変更前の入口・ゲーム表示・検証スクリプトでも同じ失敗を再現した。今回の実装範囲はタイトルと終了遷移のため、ダイス操作は変更していない。
- 1200×900と390×844でタイトル画面を撮影し、看板、開始メニュー、著作権表示とバージョンの配置を確認した。
