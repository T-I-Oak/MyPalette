- 期待: アトリエ内にパレットと作品が配置され、情報欄と各操作を参照できる。
- 結果: [field-A.png](evidence/field-A.png)で同一制作空間、パレットより上側の作品、信用/日付/名声と各エリアを識別した。体験の好ましさや通常カードをキャンバスとみなす判断はD03と区別する。
- 対応: 02 §2.1・2.2・2.4・5.6、03 §2.2・2.8の静止画面。状態変化の全経過は対象外。

## M02: 物理部品の揺らぎ

- 初期条件/手順: M01の画面、複数枚の手札とストックを観察し、`scatteredPlacement` と `orientPainting` の適用箇所を照合する。
- 期待: 物理部品の配置・向きが完全には揃わず、非物理UIへは適用しない。
- 結果: 手札はX/Y±1論理px・±1.5度、ストック/デッキはX±1/Y±0.45論理px・±1.5度、捨て札はX±24/Y±8論理px・±10度。作品はIDからX/Y両軸に±0.006ラジアンを加える。各適用箇所と数値を実装仕様にも記録した。出荷済みの固定32度のサムネイルは、2026-11-27のオーナー確認により情報表示として適用対象外とする（D07）。

## M12: カード下端と受け台の見え方

- 確認版0.45.0。checkAcceptanceCardSupport.cjs、diceListReviewFixtureで実際の着手操作を使用。A・1200×900・DPR3・動きを減らす設定。保存済みファイルと製品コードは変更しない。
- 観察の契機: オーナーが、カード下端が受け台よりわずかに下に見えると指摘した。
- 実測: カード表面とカード本体の高さは414px、配置計算の高さも414。左右端・中央の3点で、カード表面と配置の下端の差は0。実際のイーゼルの受け台前縁へ投影した点との差は約0.05px。カード面が前縁よりわずかに手前にあることによる投影差を含む。
- 描画: 下へ1.5pxの厚みの縁と、下へ6px・ぼかし10pxの影がある。これらはカードの論理高さに含まれない。発光/輪郭も併せて、検証ブラウザー内だけで無効にする比較を行い、高さが変わらないことをassertした。
- 目視: [通常](evidence/d03-card-lower-edge.png)・[影と縁のない比較](evidence/d03-card-lower-edge-no-shadow.png)を確認。影などを外すと、カードが受け台より下へ出て見える部分が減る。主な要因は影と厚みの縁の表現と判断する。実測は[d03-card-lower-edge.json](evidence/d03-card-lower-edge.json)。
- 扱い: 配置の大きな不一致は確認できなかった。見え方の観察はCARD-01へ記録し、カンバス表示時の上端支持不足とは分ける。今回の製品の描画は変更していない。
