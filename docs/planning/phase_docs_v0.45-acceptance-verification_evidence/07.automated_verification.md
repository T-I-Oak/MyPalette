## 初回失敗と検証コードの修正

初回ログは`*-initial.txt`として区別する。開発者入口を要するDicePresentation/SpecialFramesへゲーム入口を渡した実行はタイムアウトであり、製品の失敗とは判定しない。正しいdev.htmlで再実行した。

- checkDiceGraphics: 画像URLがbase外の`/assets/`だった。`/MyPalette/assets/`へ合わせ、色合成18組・特殊面10種を再実行。
- checkDiceList/checkIconDescriptions/checkUseDice: 旧版固定の比較をpackage.jsonのversion参照へ変更。
- checkPaletteArea: 手札操作層は追従配置の0寸法アンカーであり、パレット下端余白の比較対象ではない。実装の下端4論理pxを固定倍率で割り戻して検証する。36pxの操作領域・viewportの高さ・同じcanvasの維持等は残す。
- checkDiscardArea: 目標にも説明操作が追加されているため、最初のCardIconは効果とは限らない。fixtureで設定した達成時効果のPaintingBlock.rewardを選択し、EffectDetailsの既存assertを維持する。
- 追加fixtureの情報確認は、合成した出荷状態の表示への同期を明示する。日末fixtureの発注必要枚数は要求01の定義どおり3→5（+2）とする。これらは製品の機能修正ではない。
