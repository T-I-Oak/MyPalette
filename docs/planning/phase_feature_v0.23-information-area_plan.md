# v0.23 情報表示エリアの正式化

- 予定バージョンは `0.23.0`。
- 開発ブランチは `feature/v0.23-information-area`。

## 開発スコープ

ゲーム本体 `/MyPalette/` の情報表示エリアを、レイアウトA/Bで仮UIから正式UIへ置き換える。現在の進行状況、出荷済み作品、進行記録、終了時の表示と操作は、具体案を作る際の確認材料とする。正式UIに何を表示するか、配置・見た目・操作・演出をどうするかは、実装フェーズでオーナーと調整して決める。

## 対象外

レイアウト全体の正式化、他エリアの独立した改修、個別効果UIの刷新、過去の自己記録との比較・ランキング、ゲームルールの変更。

## 完了条件

- 合意した表示項目・配置・操作・演出を正式UIで確認できる。情報と操作可否は対応するゲーム状態に同期する。
- レイアウトA/B、リサイズ、固定倍率変更で表示と操作を確認する。演出を実装する場合は通常時と「動きを減らす」設定で、表示の更新時点と最終状態を確認する。
- 初日から日末・出荷・ゲーム終了・再プレイまでの既存進行を確認し、合意したUIの具体的な完了条件とオーナー検証の判断を実装報告に記録する。

## 実装・テスト方針

1. 実装フェーズで、既存表示と関連要求をもとに具体案を提示する。表示項目・配置・見た目・操作・演出についてオーナーと調整し、合意したまとまりから実装する。各まとまりが確認可能になった時点で操作手順と期待結果を示し、フィードバックを反映してから次に進む。
2. 既存のゲーム状態・操作とエリアの座標変換を使う。出荷の表示や移動を変更する場合は共通カードシーンを使い、実カードの個体と表示上の所属の更新順を維持する。合意した仕様を関連する実装仕様に反映する。
3. 合意した仕様に対応する対象テストとブラウザー検証を行う。実装の終了草案を提示する前に `npm.cmd test` と `npm.cmd run build` を実行し、対象テストと合わせて結果を記録する。
