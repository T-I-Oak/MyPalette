- 達成処理と演出の例外処理を調べたが、自動でタイトルに戻る経路は確認できなかった。オーナー判断により、現時点では再検証を行わず、再発時に本格調査する。バックログに発生状況と保留理由を記録した。一局を通す実機確認は完了していない。
- 旧評価用の設定エラー表示と「入口へ戻る」の生成処理は別のバグ項目として記録した。MP28-02 との因果関係は未確認。
- 実装再開に伴い v0.28.5 に更新した。アプリの処理に変更はないため、個別の回帰テストは追加していない。`npm.cmd test`（制限外）は全216件成功し、`npm.cmd run build` も成功した。

## 初回実装

- 対象は iPad の Safari。確認先は [My Palette](https://t-i-oak.github.io/MyPalette/)。
- ゲーム開始後に初日の開始ボタンが表示されず、横向きでもサイドパネル開閉ボタンが残った。実機のスタックトレースからカードアイコンの `ResizeObserver.observe()` 呼び出しで停止することを特定した。Safari が受け付けない `device-pixel-content-box` の指定を削除し、既定の監視方式を使う修正を v0.28.3 で公開した。
- カード詳細を開くと Safari のダイアログの初期フォーカスが Step 0 に移った。初期フォーカス先を「閉じる」に指定した v0.28.4 を公開した。
- 起動時のエラーを実機で収集するために追加した診断欄とイベントリスナーは、オーナー確認後に削除した。
- ゲーム設定とダイスの出目用画像をタイトルで並行して読み込み、準備中は全メニューを無効にする。選択した項目の絵はカラーで表示し、ほかの項目の絵はモノクロにする。パレットに出るエラー通知は中央に配置し、背景を付けた。
- タイトルに共通ボタンスタイルを適用し、ラベルを折り返さず、表示中の項目の幅をそろえた。「記録」と「ギャラリー」の画像とメニュー定義を追加した。両項目の解放条件と遷移先は今後の開発で扱い、現時点では「ゲーム開始」のみ表示する。
