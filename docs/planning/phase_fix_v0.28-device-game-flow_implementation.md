# v0.28 実機でのゲーム進行対応・実装報告

## 最終実装（v0.28.40）

オーナー合意により、Safariでゲームを開始できる修正に加え、0.28で確認済みの初期フォーカスとタイトル改善を残す。ゲーム実装は、実機で9日＋26日を完走したv0.28.5と同一。最終整理の版番号は、過去の検証版と重複しない0.28.40とした。

- **起動修正**: 実機のスタックトレースから、カードアイコンのResizeObserver.observeでSafariが受け付けないdevice-pixel-content-box指定を使っていることを特定。既定の監視方式へ変更した。念のためのブラウザー分岐や例外の握りつぶしは追加していない。
- **カード詳細**: showModal時にStep 0へ初期フォーカスが移る問題を確認し、閉じるボタンを初期フォーカス先に指定した。
- **読み込み**: ゲーム設定と出目画像を開始前に並行取得し、準備中は全メニューを無効化する。選択したメニューの絵はカラー、ほかのメニューの絵はモノクロにする。パレットのエラー通知も中央で読めるようにした。
- **タイトル**: 共通ボタンスタイル、ラベルの折り返し防止、幅の統一を適用。「ゲーム開始」「記録」「ギャラリー」の定義と別々の画像を保持する。後二者の解放条件・遷移は未実装で、現在はゲーム開始だけ表示する。

## 最終実装に含めない調査用変更

MP28-02調査中の解像度変更、同一寸法resize抑止、DOMダイス、物理/WebGLの除去、イーゼル変更、Canvas削減、画像削除・縮小、簡易操作画面、タイムライン変更、診断ログとコピーUIは含めない。Three.js・物理ロール・イーゼル・画像表示は調査開始前の通常実装を維持する。正式版へ取り込むべき負荷改善はバックログに残した。

## MP28-02の調査結果と保留

通常プレイ中に突然タイトルへ戻る現象は複数回発生。ログでは着手・効果・達成・日開始・日末など複数の範囲で旧ページの記録が途切れ、新しいページIDで起動していた。手動の戻る/再読み込みではないとの報告。アプリ例外から自動的にタイトルへ戻す経路は確認できず、原因は特定していない。

iPadOS更新の申告後、再発を確認したv0.28.21の公開成果物をそのまま復元して22日・約22分を完走。さらにSafari起動修正を保持した調査開始前v0.28.5で、オーナーが9日＋26日の完走を報告した。後者の同一ページ継続や経過時間は未記録。OS/Safariや端末状態など環境の変化の可能性はあるが、更新前後のOS版と因果関係は未特定。

現状は「原因未特定・現環境で再現せず、再発待ち」としてバックログへ残す。原因修正完了とは扱わない。通常構成での再現を確認できない状態で、二分比較や推測修正は続けない。

復元先を誤ってv0.27へ戻した際にはSafari起動修正も戻ってしまい、開始ボタンが出ない回帰を起こした。v0.28.5への復元で訂正済み。今回残す実装はその訂正後のもの。
