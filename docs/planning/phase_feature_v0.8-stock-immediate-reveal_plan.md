# v0.8 ストックの即時公開

## 開発スコープ

- 予定バージョンは `v0.8.0`、開発ブランチは `feature/v0.8-stock-immediate-reveal` とする。バージョン設定は実装フェーズ開始時に更新する。
- 公開カードを取得した直後に、同じグレードのストックの次のカードを公開する。チラシによる発注、カード効果、手札交換に共通する取得処理へ反映する。
- 複数枚を取得する効果は1枚ずつ処理する。直前の取得で公開されたカードも次の回で選べる。
- ターン終了時は、その時点で公開中のカードを各ストックの一番下へ送り、次の先頭を公開する。当ターン中に取得で繰り上がったカードも対象に含む。

## 承認済みの要求仕様変更

- `docs/requirements/01.game_rules.md` の「4-2. ストックからのカード取得に関する共通ルール」で、次の公開を原則ターン終了時に行う段落を「公開カードを取得した直後に、そのグレードのストックの一番上のカードを公開する。」へ差し替える。
- 同文書の「ストックのリフレッシュ」で、取得後に公開カードがない場合は一番下へ送る処理を省くという例外段落を削除する。
- `docs/requirements/07.other_effects.md` の「3.2 ストックからのカード獲得」で、効果の定義文「ストックから絵画カードをN枚獲得する。」を「公開カードから1枚を選んで獲得する処理をN回繰り返す。」へ差し替える。

## 対象外

- 今回のストック取得・公開ルールに関係しないゲームルールや画面構成の変更。

## 実装・テスト方針と完了条件

- 評価用ゲームの共通取得処理で、カードを取り除いた直後に先頭カードの公開状態を更新する。空のストックでは公開カードなしとし、取得可能なカードが尽きた場合はその時点で取得を終える。
- 評価用ゲームの画面で、取得直後に公開表示が更新され、複数枚取得では同じグレードから続けて選べることを確認する。
- 最後の1枚を取得した場合、空のストックに手札交換でカードを戻した場合、取得直後に公開したカードがターン終了時に入れ替わる場合を関連テストで確認する。
- 承認済みの要求仕様3か所と評価用ゲームの実装仕様に反映し、対象テスト、`npm.cmd test`、`npm.cmd run build` の結果を実装報告に記録する。
