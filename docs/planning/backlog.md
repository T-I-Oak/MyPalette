# バックログ

## 要望・バグ指摘

以下の順序で開発を進める。各項目の具体的なスコープと完了条件は、着手する計画フェーズで定める。

### 1. UIの実装

ゲームの評価を踏まえて、ゲームの見た目を設計・実装する。

- ゲーム本体の入口 `/MyPalette/` とローカル開発者用入口 `/MyPalette/dev.html` の分離、および本番成果物からの開発者用ツールの除外は実装済み。プレイヤー向けのゲーム本体を作る際も、開発者向けの評価プレイ・カード設定・ダイスやアイコンの確認画面を維持する。

- 組み換え式UI: エリア間移動ライブラリと評価用ゲームへの試験適用は完了。残る作業は、プレイヤー向けワイド画面への適用と、画面サイズに合わせて縦横比を保ったまま画面全体を一様に拡縮する仕組みの実装。
- 狭い画面向けのエリア配置・倍率・表示方式を設計する。開閉に伴うエリアの位置と倍率を、[エリア間移動の設計仕様](../spec/13.area_transition.md)の座標変換に渡せるようにする。
- ダイス単体・群、3D物理ロール、面表示、浮遊する結果表示、面構成の条件検索、専用動作確認画面は実装済み。残るダイス作業は、既存ゲームの進行・獲得・リロール・消費処理への組込みとゲーム画面での配置。
- ゲーム本体への3Dダイス組込み時に、プレイヤー向けの入口で読み込むJavaScriptの容量と、ゲーム開始から初回のロールが可能になるまでの時間を測る。開発者向け画面も含めてビルド時の3Dダイス関連のサイズ警告を解消し、現行の500 kBしきい値で警告が出ないことを完了条件とする。
- カード: ステップに応じた表示などを実装する。
- カンバス: カードの絵画がカンバスに置かれる演出などを実装する。
- パレット: ダイスが置かれると画材が表示される演出などを実装する。

### 2. 追加要素の実装

ゲームの評価とUIの実装を経て、ランキング、アチーブメント、ギャラリーを実装する。
