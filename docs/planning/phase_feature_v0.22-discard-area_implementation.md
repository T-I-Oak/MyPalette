## 根本対処：45枚の共通管理への置換（0.22.0）

### オーナー指定

- カード消失の局所修正を繰り返さず、今のうちに根本対処する指示を受領。
- 実カードは常時どこかに表示し、非表示の例外は達成時のカンバス演出のみ。
- シャッフル順の変更は中央に全カードが集まった瞬間だけ。
- 手札の増減と残りカードの再配置、イーゼルの増減・再配置も連続移動する。
- イーゼルの画面外との出入りに合意。出荷済みは当面情報エリア内の表向きの山とする回答を受領。

### 最終構成

`CardSceneState`・`CardScene`・`cardSceneLayout`・`cardScenePlans`・`cardSceneTimeline`へ責務を分離した。実カード45IDはそれぞれ一つのCardとDOMを保持する。位置・角度・表裏・重なり・透明度・現在の所属と移動中の所属を共通管理し、枚数もそこから計算する。ゲーム上の状態と演出中の表示状態を分け、後続処理の状態へ先回りして表示しない。

手札・ストックのエリア表示は操作とラベルを担当する。プレイ表示は同じイーゼル個体を保持し、現在の位置・向き・倍率からカード支持面の投影を渡す。撤去後のイーゼルは画面外で保持し、再度プレイされたときに再利用する。カードとイーゼルは移動対象以外の再配置も含めて同じ時間進行で動く。出荷済みカードは情報エリア内へ運び、一覧は読み取り用として残した。

通常ゲームの移動用カード複製、山や手札全体を隠す条件、エリア別の途中描画用上書きを廃止。旧stockEffects/stockHandEffects/deckEffects/deckPresentation/playEffects/playCardFlight/playEffectStateと旧方式の補助描画を削除した。評価用表示の移動処理とダイスのフロートアイコンは今回の実カード管理の対象外として維持する。拡大・選択・一覧のカードも実カードとは別の参照表示である。
