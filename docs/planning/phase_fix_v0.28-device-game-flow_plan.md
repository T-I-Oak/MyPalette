# v0.28 MyPalette の実機動作対応

- 開発ブランチは `fix/v0.28-device-game-flow`。
- 予定バージョンは `0.28.0`。実装フェーズ開始時に `package.json` と `package-lock.json` を更新する。
- 対応項目はバックログの「MyPalette を実機で動作するようにする」。オーナーとの合意に基づき、初日の開始からゲーム終了後のタイトル復帰までを含む一局全体を対象とする。

## 開発範囲

対象実機のブラウザーで公開 URL を開き、ゲーム開始、日ごとの仕事の開始・プレイ・終了、翌日への移行、ゲーム終了、タイトルへの復帰までを動作させる。

## 対象外

ゲームルールの変更、正式リリース、配信方式の刷新。最終名声値の表示は、既存のバックログ項目「ゲーム終了画面の正式化」で扱う。

## 実装方針

1. 実装フェーズで、`MP27-01` の対象実機の機種・OS・ブラウザー、失敗した操作と症状を確認する。公開 URL で確認できる現象と再現手順を記録する。
2. 実機で進行を妨げる問題を切り分け、原因を確認できたものから修正する。先に見つかった問題の修正後も、一局を通して操作し、後続の問題があれば調査・修正する。
3. 修正箇所の回帰を確認し、全テストと本番ビルドを実行する。本番プレビューで既存の起動・日次進行・終了・再開始の検証を行う。

## 完了条件

対象実機で公開 URL を開き、次の操作を一局通して確認する。

1. タイトルで `0.28.0` を確認し、「ゲーム開始」から「今日の仕事を始める」へ進む。
2. 手札とダイスの出目が表示され、日中のプレイと仕事の終了を操作できる。信用が残る間は翌日の仕事を開始できる。
3. 信用が0になった日の処理を終え、ゲーム終了画面から「タイトルへ戻る」でタイトル画面に復帰できる。

確認した機種・OS・ブラウザー、公開 URL、表示バージョン、操作手順と結果を記録する。公開版での最終確認は対象バージョンの配信後に行う。
