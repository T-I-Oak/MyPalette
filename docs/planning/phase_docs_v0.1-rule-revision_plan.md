# ゲームルール見直し計画

## 合意内容

- 作業ブランチ: `docs/v0.1-rule-revision`
- 予定バージョン: `0.1.0`。設定値の更新は実装開始時に行う。
- オーナーの指示に基づき、今回に限り `docs/requirements/` の該当要求を修正する。

## スコープ

1. 初期デッキは既存の7枚を維持する。
2. 注目判定、注目カウント、色がすべて異なる場合のボーナスを廃止する。初期値、公開情報、表示・演出、取得処理の参照も整理する。
3. 達成に使用したダイスを消費し、そのターン中は使用不可とする。消費は破棄ではなく、永続ダイスは翌ターンに再び使用可能になる。
4. チラシは0枚、制作途中の進捗は0から開始する。
5. ターン終了時、特殊面のダイスを除いた未使用の画材ダイスを最大2個消費してチラシを制作する。ダイス1個で進捗1、進捗2でチラシ1枚完成。進捗1は翌日に持ち越す。進捗1からダイス2個を使うと1枚完成し、次の1枚の進捗1が残る。
6. 特殊面のダイスはターン終了時に消費する。既存の特殊面効果の翌ターン予約との整合を確認する。
7. チラシ制作後も残る未使用の画材ダイス1個につき信用を1減らす。最低値は0で、信用0ならゲーム終了。従来の未達成時の信用−2を廃止する。
8. チラシによる発注時は、必要枚数を消費して公開ストックからカード1枚を選び、捨て札に置く。必要枚数は初回3枚、以降5枚、7枚と発注のたびに2枚ずつ増える。
9. 未使用・消費済みダイスの識別、達成時の使用ダイス選択、チラシ枚数・途中進捗・次の発注必要枚数、信用減少の結果を、関連する情報・操作・視覚表現要求に反映する。

10. カード効果として、任意の所持画材ダイス1個を選択して破棄する効果を追加する。永続・一時の両方を対象とし、消費と異なり翌ターンに戻らない。アイコンはダイス＋ゴミ箱とする。

- `docs/requirements/06.dice_effects.md`、`07.other_effects.md`: ダイス破棄効果の定義・対象・アイコンを追加し、消費済みダイスと効果の関係を照合して必要箇所を更新する。
- `docs/requirements/04.effect_conventions.md`、`05.icon_presentation.md`: 新ルールと矛盾する参照があれば整合させる。チラシの具体的な図柄は独断で追加しない。
- `docs/planning/backlog.md`: 対応した要望の整理。

## 対象外

- ゲーム本体、チラシやダイス消費のプログラム実装。
- 新規画像・具体的な画面レイアウトの制作。
- 共通リポジトリの編集、公開設定、今回の作業中のmasterへのマージ・push。
- 合意済み変更以外のカード構成やゲームバランス調整。

## 確定した境界条件

- ターン終了時、未使用の通常面の画材ダイスを最大2個まで必ず消費してチラシを制作する。
- チラシが必要枚数に達したら自動で発注する。必要枚数を消費し、次回必要枚数を2枚増やす。
- 全ストックが空の場合はカード取得だけが失敗する。チラシの消費と次回必要枚数の増加は通常どおり行う。チラシ制作・発注の進行をカードの取得可否に依存させない。
- 消費済みダイスはリロール・面変更・特殊面効果の即時適用の対象外とする。破棄効果では選択できる。
- ターン終了時は、未使用の特殊面ダイスの効果を翌ターン用に予約してから、そのダイスを消費する。
- 破棄効果は所持ダイスがなければ何も起こらない。アイコンは「ダイス＋ゴミ箱」を採用する。
- 将来のチラシ制作枚数に関するアチーブメントは、今回実装・仕様追加の対象としない。

## 完了条件・検証方針

- 合意されたルールが基本ルールと関連要求に一貫して記載されている。
- 注目カウント、ダイス再利用、未達成時の信用減少など旧ルールの参照が残っていない。
- チラシ制作の途中進捗、3・5・7枚の消費、未使用画材による信用減少を具体例で照合する。
- 上記の確定した境界条件が関連する効果仕様と矛盾せず、全ストック枯渇時にもチラシ消費と必要枚数の増加が続く。
- 既存素材を変更しない。
- `git diff --check`、全テスト `npm.cmd test`、本番ビルド `npm.cmd run build` を実行し、結果を実装報告に記録する。
- 文書を文字列比較するだけのテストや、未実装のゲーム挙動を実装済みと扱うテストは追加しない。
