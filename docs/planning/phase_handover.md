- 実装開始時にバージョンを0.4.0へ更新する。
- 通常面の中央に画材記号と色文字を大きく表示する。
- 永続は色付き記号と白文字、一時は白い記号・色付きの縁と文字を基本とする。
- 画材画像は既存のgrayscale素材を着色し、fixed素材を重ねる。
- 結果画像はロール中は非表示とし、確定後にダイスから浮かび上がって上下に漂う。
- 黄色の視認性と特殊面の結果表示は、実装を提示してオーナーの判断を得る。
- 既存ゲームへの組込みは対象外。
- 要求仕様（`docs/requirements/`）を変更する前に、対象ファイル・該当箇所・修正前後の内容・変更理由をオーナーへ提示し、明示的な修正許可を得ること。今回の表示方針や計画への合意を修正許可とは扱わず、許可された内容だけを反映すること。
- 完了済みのゲーム評価をバックログから削除する。
- 共通リポジトリは参照専用とする。
