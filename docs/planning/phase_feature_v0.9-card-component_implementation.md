# v0.9 絵画カードコンポーネント 実装報告

- バージョン設定を 0.9.1 に更新した。評価用ゲームの手札、制作中、出荷済み、公開ストック、カード選択に Card を組み込んだ。
- 絵画素材は制作ステップに応じて斜めに重ね、縦横比を保って全体を表示する。Step 0〜2 のタブは目標と効果を切り替え、実際の制作段階を明るさで示す。
- 目標と効果を独立した枠でまとめる。目標は選択肢ごとに行を分け、行を等間隔に配置する。ゲーム操作はカードの外に置き、効果の説明は日本語・英語の翻訳リソースから表示する。
- 手札は上、盤面に置くカードは下に薄い断面を表示する。配置時の微小な傾きと位置のずれは、同じエリアにある間保持する。
- エリア間移動は既存の移動管理を利用する。評価用盤面は現在のDOMを維持し、移動レイヤーはカードの描画を引き継いだ Card を使う。山札との移動では、表から裏、裏から表とも同じ向きに半回転する。
- カード本体は幅294px、高さ約414pxの基準寸法で組む。シーンがグリッドで表示枠を割り当て、エリアの幅比と高さ比の小さい方を内容全体に適用する。基準寸法は手札1236 × 480px、制作中318 × 480px、ストック・出荷済み966 × 500pxとした。移動中も表示幅から倍率を求め、同じ縦横比を維持する。
- 手札は4枚まで横に並べ、5枚以上は均等に重ねる。達成可能な手札には発光を表示する。
- 表向きのカードはタップで画面中央に拡大表示する。カード本体を再度タップするか「閉じる」で閉じる。タブとアイコンの説明を操作でき、カードに対応する操作ボタンを拡大表示の下に置く。
- 出荷済みカードは完成画と4等分したタブを表示する。`Done` タブの証明書には作品番号・作品名・My Palette Atelierを載せる。上部の作品名は1行で全文が入るよう、必要な場合だけ文字を縮小する。
- ストックはグレードごとに山を描き、カードの厚み分ずつ上へ重ねる。公開カードは山の最上段に表向きで描く。各カードの位置と角度の微小なずれは、同じエリアにある間保持する。

## オーナー検証

- 表面と厚み・断面の方向は見本で承認済み。ストックの重なりも承認済み。
- オーナー判断により、手札5枚以上の重なり、達成可能の発光、プレイ・達成・取得時の移動と裏返しの細かな調整は、実ゲームへの組み込み時に行う。
- CARD-01（0.9.1） 拡大表示はオーナー確認済み。表向きのカードをタップすると中央に拡大表示される。拡大したカードの本体をタップするか「閉じる」で戻り、操作可能なカードではカード下のボタンから既存の操作を実行できる。
- CARD-02（0.9.1） 出荷済みカードの証明書と、長い英語名を省略せず上部に表示する見本をオーナーが確認した。英語名は見本用の仮題を使用した。
