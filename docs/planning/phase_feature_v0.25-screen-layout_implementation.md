# v0.25.0 ゲーム画面全体のレイアウト正式化 実装報告

## 実装結果

- 固定倍率は表示枠の幅・高さに対して共通の基準540×540 CSS pxから算出する。高さ360pxでは約67%、幅390pxの縦長画面では約72%になる。
- アトリエを全面に敷き、プレイエリアのイーゼルの足元に床と影を配置した。ストック・捨て札・デッキは正面から見た木枠付きコルクボードにまとめ、Bでは3エリアと一緒に開閉する。
- コルクボード上のエリア名とグレード別枚数を付箋にした。手札の見出しと上部オフセットを削除し、カード描画に使う領域を広げた。
- 仕事開始・終了ボタンはプレイエリアの上端中央を拡縮の基準とし、プレイ中のカードの手前、開いたコルクボードの奥に置く。
- 情報エリアの日数と名声を作業日誌にまとめた。名声の現在値と増減効果は同じアイコン描画を使う。日誌は `Day 88` が収まる66px幅とした。
- ゲーム中のバージョン表示を削除し、タイトル画面での表示をバックログに追加した。着手順は今回のレイアウト正式化、タイトル画面、実機検証用GitHub Pages公開の順とした。
- 選択モーダルと結果報告モーダルの外観は、それぞれを扱う開発で決める。
