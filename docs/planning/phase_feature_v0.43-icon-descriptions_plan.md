# MP40-05 アイコンのホバー説明の改善

## 合意事項

- 2026-11-26、オーナーがMP40-05をMP40-03／MP40-04より先に進める方針を指定し、以下の計画に合意した。
- 予定バージョン: v0.43.0。実装開始時にpackage.json・package-lock.jsonを更新する。計画では更新しない。
- ブランチ: `feature/v0.43-icon-descriptions`。

## 開発スコープ

- 目標ダイスアイコンのホバー説明を改善する。
- 目標・プレイ時・達成時の見出しアイコンへ説明を追加する。
- 既存の効果アイコンの説明表示に合わせ、タッチでも説明を確認できるようにする。
- 目標アイコンの面検索と説明表示を両立させる。
- 必要な関連仕様と検証を更新する。

## 対象外

- MP40-03／MP40-04の所持ダイスの長押し情報表示。
- MP40-10の効果獲得の表示変更、個別効果UIの正式化。
- QA-01全体、MP40-14の旧ダイス一覧生成削減。
- MP43-01の固定倍率領域の倍率計算。今回のオーナー指示はUIバックログへの追加のみ。
- 要求仕様の変更、共通リポジトリの変更。

## 完了条件

1. 目標ダイスアイコンの意味と条件、および目標・プレイ時・達成時の各見出しの意味を説明で確認できる。
2. ホバーとタッチで説明を確認でき、既存の効果アイコンの説明と操作方針が整合する。
3. 説明の開閉が面検索やカード操作と競合せず、意図しないゲーム状態の変更を起こさない。
4. レイアウトA/B、画面端、狭い画面、リサイズ、固定倍率変更で説明が読めることを確認する。
5. 関連テスト・ブラウザー検証、全テスト、本番ビルドの結果を実装報告へ記録する。
6. 説明内容と操作感について、確認可能な実装でオーナー検証を提示し、判断と対応を記録する。

## 実装方針

- `src/cardIcons.js`、`src/iconPopovers.js`、`src/icons/`とカード表示側の呼出経路を確認し、既存の説明生成・開閉処理を再利用する。
- 効果説明の契約は`docs/spec/16.effect_common_ui.md`、共通アイコンは`docs/spec/12.shared_icons.md`、面検索は`docs/spec/19.palette_operation.md`を参照する。
- 既存説明はホバーで一時表示、タップで保持、再タップまたは外側タップで閉じる。Tab対象外・キーによる開閉なしの既存方針に合わせる。
- 目標アイコンの既存タップ検索と説明保持の入力競合を調査し、両立する操作を設計する。具体的な文言・配置・タッチ導線は実装時に提示してオーナー確認を受ける。
- 説明の再描画・破棄時にポップアップを解放する。新規の標準モーダルは使用しない。
- 操作判定や状態管理など複雑な変更は実装前にテストで仕様を定義する。

## テスト方針

- 変更モジュールに対応する実装テストで説明内容・開閉・解放と操作競合を検証する。既存検証で十分な箇所は再利用する。
- `scripts/checkEffectCommonUi.cjs`、`scripts/checkDiceSelection.cjs`、カード操作・詳細・面検索の既存検証から対象を選び、必要なケースを追加する。
- ホバー表示・解除、タップ保持・再タップ・外側タップ、面検索との両立、カード詳細や着手への誤伝播防止を確認する。
- A/B、画面端、狭い画面、リサイズ、固定倍率、タッチでの表示を確認する。既存の日英説明を変更する場合は両言語を確認する。
- 実装終了草案の提示前に`npm.cmd test`と`npm.cmd run build`を実行する。
- 常用開発サーバーをAI側で再起動しない。実機確認と自動ブラウザー検証の結果は区別する。

## オーナー検証予定

- ICON43-01: 目標ダイスの説明内容、タッチ時の説明確認と面検索の両立。
- ICON43-02: 目標・プレイ時・達成時の見出し説明の内容と操作感。
- 実装時に確認理由、操作手順、期待結果、設定・画面表示と一致する確認バージョンを示す。未回答は保留とみなさない。
