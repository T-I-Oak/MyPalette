# ダイス結果アイコンの出現・浮遊アニメーション復元計画

## 合意内容

- 対象: バックログ先頭「ダイスのフロートアイコン表示アニメーションのデグレード」。
- 開発ブランチ: `fix/v0.18-dice-result-animation`。
- 予定バージョン: `0.18.0`。実装開始時にpackage.jsonとpackage-lock.jsonを更新する。
- オーナーは計画フェーズ開始と、本書のスコープ・対象外・完了条件・バージョン・ブランチ名に合意済み。

## 現状と根拠

- [ダイスコンポーネント仕様](../spec/10.dice_component.md)は、確定時に0.7秒で下45px・倍率0.45・透明から出現し、その後3秒周期・7pxの上下動・左右±3度の回転で浮遊すると定めている。
- `src/dice/DiceScene.js`は各ダイスの結果に応じて結果DOMのhiddenを切り替える。結果DOMと子のDiceResultMotionは維持されている。
- 現在の`src/dice/layout.css`と`states.css`には出現・浮遊のアニメーション定義がない。
- コミット`6e6b787`のlayout.cssにはdice-emergeとdice-float、および動きを減らす設定への対応が存在する。削除経緯と実際の発生条件は実装時に調べる。
- 再ロール準備では、現在の表示位置を取得して本体へ吸収する処理があり、state-returningでCSSアニメーションを停止している。
- 通常のゲーム更新で結果DOMを接続したまま維持する契約があり、各ダイスの出現演出を全件確定時に再始動させない。

## 開発スコープ

- 出目確定後の出現・浮遊アニメーションを既存仕様に沿って復元する。
- 通常面・特殊面、個別の確定タイミング、再ロール、消費・再利用との接続を確認する。
- A/Bレイアウト、リサイズ、固定倍率変更、動きを減らす設定での回帰を確認する。
- 修正に対応する回帰テスト・ブラウザー検証と、必要な実装仕様の整合を扱う。

## 対象外

- ストック・デッキ・捨て札・情報表示などの正式UI。
- 長押しによるダイス情報表示、新しい演出やゲームルールの追加。
- 効果別UIの正式化、物理ロール条件・出目決定方法の変更。
- 共通リポジトリとオーナー管理の要求仕様の変更。

## 完了条件

1. 各ダイスの出目確定時に、仕様の0.7秒の出現から浮遊へつながり、突然表示されない。
2. 通常面・特殊面の両方で動作し、群全体の完了と後続のゲーム処理を演出待ちで遅らせない。
3. 先に確定したダイスの演出が、全件確定・通常の画面更新・リサイズ・固定倍率変更で再始動しない。
4. 再ロール時の吸収が表示中の位置から連続し、次の確定で出現が再生される。同じ出目が続く場合も確認する。
5. 消費時の非表示、再利用時の結果再表示、選択輪郭・ドラッグ・達成時の画材飛行を損なわない。
6. A/Bレイアウトで確認し、動きを減らす設定では長い出現・継続的な浮遊を抑え、結果が正しく見える。
7. 対象テスト・全テスト・本番ビルドの結果と、必要なオーナー検証の判断・対応を実装報告へ記録する。

## 実装方針

- Git履歴と実ブラウザーで原因・再現条件を確かめ、既存DOMとCSSの責務に沿う最小限の修正にする。
- 出現は外側、浮遊は内側の要素で扱う既存構造を利用し、吸収用のtransformと競合させない。
- hidden解除やstate-returning解除による再生タイミングを確認し、必要な場合だけ表示状態の制御を補う。
- 複雑な状態制御が必要になった場合は、先にテストで期待動作を定義する。
- 仕様書は現在の意味と実装契約に必要な記述だけを更新する。バックログ項目の完了削除はレビュー承認後に行う。

## 検証方針

- 対象テスト: 変更に応じたdice・paletteSnapshot・readyMotion等の既存テストと追加する回帰検証。
- ブラウザー: 開発サーバーのゲーム本体を使い、確定直後・出現途中・浮遊の時間経過を確認する。CSS文字列の存在確認だけを復元の根拠にしない。
- 複数ダイスの個別確定、同じ出目での再ロール、通常更新、吸収、消費・再利用、特殊面、達成演出、A/B・リサイズ・倍率変更、reduced-motionを確認する。
- 全テスト: `npm.cmd test`。
- 本番ビルド: `npm.cmd run build`。
- 必要なオーナー確認には一意のID、確認理由、操作手順、期待結果、確認バージョンを付け、判断を実装中に得る。未回答を保留として扱わない。
- 計画フェーズではソース変更、バージョン更新、実装検証は行わない。
