# 日次の自動開始と日付演出の実装報告

## 実装内容

- 計画どおり0.31.0から実装を開始し、オーナーフィードバック対応後の最終確認バージョンは0.31.3。
- プレイヤー向けの開始ボタンを撤去した。初日は日付演出から、翌日は日末の片付け・ストック更新完了から自動開始する。
- `dayStartFlow.js`が開始の重複を防ぎ、中央での翌日更新と帰着後の朝の開始を分離する。終了時は進めず、破棄時はAbortSignalで後続を中止する。
- `dayStartMotion.js`が既存InfoDayそのものを移動層へ載せ、元の場所には寸法だけの空要素を置く。各フレームで帰着位置と画面中央を読み直す。破棄時には同期的に元へ戻し、直後の再開始と競合させない。
- 通常は移動520ms、中央保持480ms、帰着520ms、中央倍率3倍。初日は中央の通常サイズから拡大して始める。初日の拡大は1フレーム当たりの進行を1/30秒までに制限し、初期描画負荷で中間表示が飛ばないようにする。動きを減らす設定では左上で更新し220ms待つ。
- エンジン・セッションの日次処理は変更せず、初日配分・公開・ドロー・権利付与・予約効果・物理ロールの既存順序と、評価用の同期進行を維持した。
- 開始前の観察が必要なブラウザー検証には、検証ドライバー`dayStartGate.cjs`を追加した。受信する開発モジュールに待機ラッパーを挿入する方式で、正式ソースにテスト用の停止分岐はない。`checkDayStart.cjs`と本番起動検証はこの制御を使用しない。
- 開発手順、ゲーム進行仕様、情報表示仕様を更新した。共通リポジトリ、要求仕様、カード設定は変更していない。
