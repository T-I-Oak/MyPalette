## 閉じたボード内の演出省略（0.36.1）

MP36-01の確認後、同じ実装フェーズの計画済みスコープとして実装した。

- 初日配分・ストック公開切替・再構成の開始時に、現在のレイアウトと実際のスライド進捗を参照する。Bで進捗0の場合だけ省略し、閉じるスライド中は継続する。
- 初日7枚配分は同じカード移動を時間0で確定する。
- ストックの切替・公開・補充は、非表示時に順序と表裏をまとめて時間0で確定する。表示時は開始時の判定を裏返し・最下段挿入・次の公開まで共通使用する。
- 再構成は非表示時に広げる・集めるを省略し、ゲームの再開コールバックとシャッフルを一度だけ実行してデッキへ時間0で移す。後続ドローは既存どおり実行する。
- 手札返却・取得・手札と場から捨て札への回収・デッキから手札へのドローは省略しない。動きを減らす設定は維持する。
- 演出途中の開閉では開始済みの判定を変えず、別の演出の開始時に現在の状態を参照する。
- docs/spec/18.card_scene.mdと開発・検証案内を更新した。保存済み設定・共通部・要求仕様・バックログは変更していない。
