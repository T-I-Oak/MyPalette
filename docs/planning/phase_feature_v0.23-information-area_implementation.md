# v0.23.0 情報表示エリアの実装報告

対象ブランチは `feature/v0.23-information-area`。計画と照合した変更は以下のとおり。

- 情報エリアを、ロゴ、日数／名声値、信用／チラシ、出荷済みカンバスの横並びに変更した。標準寸法は固定し、信用・チラシの集約は利用可能な幅で判定する。指定の画像を使用し、チラシの原寸素材を保持した。
- 出荷済みカンバスは2枚分の幅で右寄せし、3枚以上は重ねて表示する。完成画はイーゼルからそのまま移動して傾き、到着後はカンバスからカード詳細を開ける。
- 日末はチラシを情報エリアとプレイエリアの間で移動させ、画材を1個ずつ使う。発注分がそろうと拡縮3回の後にチラシを消費し、次回必要枚数を反映する。制作後に信用減算と継続判定を行い、継続時はストックを取得する。終了時にもチラシ消費と必要枚数の変更は反映する。この処理順は実装中の合意を反映した。
- 信用は減少見込みの警告、着弾と破片、増加時の拡大を表示する。日数と名声値の増加も拡大で示す。日数は手札・プレイエリアとストックの片付け完了後に進む。ダイス準備は朝に行う。ゲーム終了時は通常の情報表示を維持する。
- 計画時の再プレイ確認は、ゲーム終了時の結果表示と再プレイ操作を削除するという実装中の指示に合わせ、終了時の表示確認に変更した。
