# v0.9 絵画カードコンポーネント

## 開発範囲

- 予定バージョンは `v0.9.0`、開発ブランチは `feature/v0.9-card-component`。バージョン設定は実装フェーズ開始時に更新する。
- プレイヤー向けの絵画カードを新規に設計する。盤面に実物のカードが置かれているような存在感を重視し、具体的な見た目は実装フェーズで実際の表示を見ながら調整する。
- `MoveObject` を継承する `Card` クラスを作る。既存のカード設定と現在ステップを受け取り、絵画とカード情報を描画する。ゲームの進行と操作可否の判断はゲーム側が担う。
- 評価用ゲームのカード表示を `Card` に差し替え、実際にプレイしながら新しい表示を確認できるようにする。

## 対象外

- プレイヤー向けワイド画面への組み込み、カードのカンバス化、ゲームルールとカード設定形式の変更。

## 実装・テスト方針と完了条件

- [視覚の要求仕様](../requirements/02.visual.md)の「絵画カード」と[情報と操作の要求仕様](../requirements/03.information_and_interaction.md)の「絵画カードの情報」を参照する。既存の絵画素材と共通の目標・効果アイコンを使い、現在ステップと他のステップの情報を区別できるようにする。
- [エリア間移動の実装仕様](../spec/13.area_transition.md)に従って既存の移動処理に接続し、移動中も新しいカードの外観が表示されるようにする。
- 評価用ゲームで手札・制作中・出荷済みのカードの外観、絵画と現在ステップ・目標・効果の読み取りやすさ、エリア間移動時の見え方を確認する。カードの詳細確認、プレイ、達成、ストックからの取得といった既存操作も確認する。
- 実物らしい存在感と情報の読み取りやすさについて、評価用ゲームで確認できる状態になった時点でオーナー検証を提示する。
- 関連するカード操作とエリア間移動のテスト、`npm.cmd test`、`npm.cmd run build` を実行し、結果を実装報告に記録する。
