# 手札エリアの正式UI実装報告

## 対象

- ブランチ: feature/v0.14-hand-area
- バージョン: 0.14.0。package.jsonとpackage-lock.jsonを更新済み。
- プレイヤー向け手札の正式UI、およびオーナー指示によるレイアウトの責務整理・共通ボタンの整備を実施した。
- 他6エリアは仮UIを維持する。共通リポジトリと要求仕様は変更していない。

## 実装結果

### 手札

- エリア名は左上の「手札」。枚数は表示しない。名前と固定倍率層に背景は付けず、手札のCanvasと内容ホストも透明とした。
- 標準描画サイズ1307×468。カード294×414、回転±1.5度・並進各軸±1の外接寸法、周囲22、カード間12の余裕から4枚分を計算する。
- 手札全体は横方向に中央寄せ。枚数にかかわらず横幅に収まれば重ねずに並べ、収まらない場合だけ両端の余白を保って均等に重ねる。
- 重なったカードも露出部分のタップで拡大する。選択による最前面化などの追加操作は行わない。ステップ参照・拡大はゲーム状態を変更せず、現在ステップの表示を維持する。
- 着手ボタンは固定倍率層でカード中心に追従する。共通i18nで日本語「着手」・英語「Start」。高さ18、上下padding0・左右3、文字幅に合わせた幅。密集時は隣接中心間隔を上限とする。
- 左上オフセット(0, 20)、右下オフセット(0, 22)。下部22はボタン18＋下余白4で、上余白は0。
- 上辺側の厚みを維持し、下辺を接地点に右上へ伸びる投影を追加した。離れるほど薄くし、エリア外の影はクリップする。形状はcard.css、質感は共通texture-ground-shadowに分離した。
- ルール・達成判定は既存GameとmatchingDiceを利用する。カードの出入りは即時反映し、操作条件は既存セッションに従う。

### レイアウトと共通UI

- レイアウトは各エリアへ固定倍率層を提供し、エリア側がfixedLayerへ描画する。拡縮する内容とは別に位置・倍率・表示を管理する。
- エリアが標準描画サイズ・左上オフセット・右下オフセットを通知する。レイアウトは固定倍率を掛けたオフセットを除いた描画矩形から拡縮倍率を計算する。
- 固定倍率層も拡縮層も割り当て範囲を超えて表示しない。ポップアップは全体画面のdialogへ表示する。
- エリア共通のボーダーを除去。内容ホストはborder-boxでpaddingを含めて割り当て寸法に収め、overflow: clipとする。
- レイアウト全体は最低高さ240×固定倍率を保証し、下回った画面では外側の表示枠をoverflow: autoで縦スクロール可能にする。画面外でも論理寸法・倍率・配置枠を保持する。
- 座標変換は描画ルートの現在の位置を参照し、スクロールイベントの発火前でも実座標に追従する。表示高さの整数丸めも除去した。
- 共通ボタンはButtonにカプセル形状、texture-raisedに塗り・枠・浅い影、states.cssに無効状態を分離した。既存テーマ変数を使い、通常・ホバー・押下を定義した。着手の小さい寸法は維持する。
- オーナー指定に従いキーボード操作・フォーカス対応は追加しない。途中で追加したフォーカス表示は削除した。
- 仮の情報UIの内容が領域を超えて操作できないケースは、標準描画高さを100から300へ変更して縮小表示する。テスト成功のために一度加えた内部スクロール用コードは削除済みで、最終ソースには含めない。

## オーナーの判断と対象外

- 配置は当初の左詰め案から、追加指示により手札全体の中央寄せへ変更した。
- ボタンの名称・寸法・共通カプセル形状、オフセットと余白はオーナー指示を反映した。
- 右上へ伸びる影についてはオーナーからokを受領した。
- 通常サイズで全体にスクロールバーが出る指摘に対応し、高さの丸めを除去した後、オーナーから消えたとの回答を受領した。
- 重なったカードはタップによる拡大だけでよいとの判断を反映した。
- 演出の追加・調整はオーナー指示により今回の対象外へ変更した。全7エリアの正式実装後に行う項目としてバックログへ記載した。評価用ゲームの既存演出は維持する。
- アイコンのホバー時説明表示の改善は、別ブランチで扱う新規作業としてバックログの「要望・バグ指摘」に記載した。今回の未回答のオーナー検証を保留にしたものではない。
- 新たに判断待ちとなっているオーナー検証項目はない。スマートフォン・タブレットの検証は相当viewportで実施し、実機検証は行っていない。

### 失敗時の調査と対応

- 旧ブラウザ検証が、固定倍率層ではなくカード内の旧ボタンを探していたため、実装に合わせて着手ボタンの参照先を更新した。
- DPRの検証がdata-area属性を持つ固定層をCanvasと誤認したため、Canvasを明示するセレクターへ変更した。
- 情報エリアの仮UIが割り当て範囲に収まらずクリックできないケースは、オーナー提案に従い標準高さ300へ変更して解消した。内部スクロールの追加は取り消した。
- 手札専用の検証ページで、本番のパネルつまみのクラス不足と、dialogのcloseイベントの待機不足を修正した。
- ダイス効果の追加検証で、検証用gainColorDiceの指定を誤り描画が停止した。カタログに従う補色IDへ修正し、面変更・破棄・再利用・獲得まで成功した。
- 初期の共通ボタン検証にはフォーカス項目が含まれていたが、オーナーの共通方針を受けて実装と検証対象から除外した。
