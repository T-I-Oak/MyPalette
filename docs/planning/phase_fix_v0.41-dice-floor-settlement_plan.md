# v0.41 ダイスの床着地判定と上限到達後の対応

## 合意内容

- 対象: MP40-01「ダイスが他のダイスの上で静止した場合は出目を確定しない」。自動再投入の上限到達後の案内・操作・復帰方法の見直しも含む。具体的な動作は実装時にオーナーと調整する。
- 予定バージョン: 0.41.0。実装開始時にpackage.jsonとpackage-lock.jsonを更新する。
- ブランチ: fix/v0.41-dice-floor-settlement。
- 2026-11-26、オーナーが上記スコープ・予定バージョン・ブランチ名に合意した。

## 開発スコープ

1. 床への着地を出目確定の条件に追加する。他のダイス上で静止したダイスは未確定のまま自動再投入する。
2. ダイス間の衝突、線速度・角速度と静止時間、上面一致度の条件を維持する。床の支持を判定する方法と数値許容差は、実際の物理接触を確認して決める。中心の高さだけで積み重なりを許す現行条件を置き換える。
3. 現行の自動再投入の上限（8回）と上限到達後の処理を調査し、案内・操作・復帰方法を実装時にオーナーと調整して実装する。既存ボタンの維持や同じロールの再開を前提としない。
4. 関連する実装仕様、検証手順・テストを更新する。

## 対象外

- 他の効果やUIの変更、ロール全体の物理パラメータ調整、他のバックログ項目。
- 要求仕様の無断変更と共通リポジトリの編集。必要な変更が見つかればオーナーへ報告する。

## 完了条件

- 床に着地し、既存の静止・上面条件を満たしたダイスは確定する。
- 水平に安定していても他のダイスの上に載ったダイスは確定せず、自動再投入する。床上の下側ダイスは通常どおり確定する。
- 衝突を維持し、複数ダイスのロールと一部リロールが完了する。対象外ダイスの姿勢・結果を保持する。
- 自動再投入の上限到達後の案内・操作・復帰方法について、実装時にオーナーと具体的な動作・完了条件を定め、その判断と検証結果を記録する。
- 調整した動作で、意図しないリロール権の追加消費や効果の重複適用がない。
- 仕様書から水平な積み重なりを確定条件に含める記述を改め、実装と検証を一致させる。
- 対象テスト、全テスト、本番ビルドを実行し、結果と必要なオーナー検証の判断を実装報告に記録する。

## 実装方針

- 主な調査・変更対象はsrc/dice/DiceGroup.js、src/dice/Die.js、src/game/palettePresentation.jsとロール要求の接続部分。
- 床接触、上側の積み重なり、傾いた静止の再現テストを先に追加し、失敗を確認してから判定を修正する。
- 再投入時の移動先・待機の解決・回数上限と、ゲーム側のfailRoll／再開処理を確認する。調査結果を踏まえ、上限到達後の動作をオーナーと調整する。
- docs/spec/10.dice_component.mdを中心に、ゲーム接続・パレット操作に関する仕様も必要に応じて更新する。

## 検証方針

- 決定的な配置・姿勢で、床上の確定と水平な積み重なりの再投入を区別する。再投入後に床上で確定することも確認する。
- 上限到達を再現し、実装時に定めた案内・操作・復帰方法、待機処理の終了、意図しないコスト消費・効果の重複がないことを確認する。
- 既存のDiceGroup、ロール要求、複数ダイス・一部リロールのテストを実行する。対象ファイルは実装に合わせて選ぶ。
- ブラウザーでレイアウトA/Bと動きを減らす設定の実装時に定めた上限到達後の動作を確認する。再現用の制御は検証内に限定し、本番コードに検証用の操作を追加しない。
- 全体確認はnpm.cmd testとnpm.cmd run build。実行結果と未検証範囲を実装報告に記録する。
- 必要なオーナー検証は確認可能になった時点で、一意のID、対象バージョン、操作手順、期待結果とともに提示し、判断を記録する。実機未確認を確認済みと扱わない。
