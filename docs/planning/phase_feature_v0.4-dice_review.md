## DICE-R01: prepare単体で空中の準備姿勢へ戻らない（解消済み、初回P2）

対象: `src/dice/Die.js:51`、`src/dice/DiceGroup.js:81`。
契約: 実装仕様10の単体API表でprepareは「ロール前の空中回転状態へ戻す」とされる。

prepareはstateとcurrentだけを変更し、停止時の中心高さを保持する。
群のready処理も姿勢を回転させるだけなので、公開APIを直接利用すると床上で回転し、ダイスの一部が床へ潜る。
確認画面は `lab.js:66` でprepare直後に別途setPosition(y=2.5)を呼び、この不具合を補っている。
将来ゲームへ組み込む側が、確認画面固有の高さ補正を再実装しないと仕様どおりにならない。

再現:

1. 固定乱数0.37のDiceGroupに通常面6枚を持つダイス1個を追加する。
2. 単体roll後、1/60秒ずつstepし、確定を待つ。
3. 公開APIのprepareだけを呼び、さらに60フレーム進める。
4. 中心Yは確定時もprepare後も約0.499991のまま。回転した箱の最下頂点Yは約-0.294645となる（床Y=0）。

期待する修正:

- 空中準備状態への移行を共通コンポーネントの責務として成立させる。
- 確認画面だけの高さ補正へ依存させず、prepare単体の契約を満たす。
- 実際に停止したダイスからprepareを呼び、結果の解除・空中位置・回転と再ロールを確認する回帰テストを追加する。

## DICE-R02: 初期配置の仕様が最終実装と一致しない（解消済み、初回P3）

対象: `docs/spec/10.dice_component.md:73`、同`:174`、`src/dice/field.js:21`。

仕様には初期配置がX間隔2.3・Z間隔2.2、位置に±0.09の揺らぎとあり、
群のrandomも初期配置へ使用すると記載されている。
最終実装のfieldSpawnはX間隔4・Z間隔2.5を基に領域内へ補正する固定配置で、
初期配置に乱数や±0.09の揺らぎは使用していない。
API利用者や配置の保守担当が仕様から実際の配置を再現できない。

期待する修正:

- 承認済みのパレット上の配置を維持する場合は、実装仕様の寸法・補正方法・乱数の用途を最終実装に合わせる。
- 配置の揺らぎを残す設計にする場合は、使用範囲から出ない形で共通の配置処理へ実装し、仕様と揃える。
- この指摘だけを理由に要求仕様を変更しない。
