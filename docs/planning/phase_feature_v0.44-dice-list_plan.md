# v0.44 ダイスリスト開発計画

## 合意内容

- 対象ブランチ: `feature/v0.44-dice-list`
- 予定バージョン: `0.44.0`。実装開始時にpackage.json・package-lock.jsonを更新する。
- 対応項目: MP40-03、MP40-04。長押しによる情報表示をやめ、ダイスリストによって所持ダイスの面構成を公開する。
- 2026-11-27 オーナー指定: 検索強調は次の検索まで保持し、リストを開き直すとリセットする。3D外観はパレットの姿勢へ追従せず、現在面を上面にする。カード詳細を最前面としてリストを操作抑止する既存方針を許容する。標準スクロールバー外観は禁止する。

## 開発範囲

1. パレット右上の固定倍率領域へ、ダイスリストを開くアイコンを追加する。OS依存の絵文字や標準ツールチップを使わず、ゲーム内の描画・説明を使う。
2. 独自のモードレスダイアログを実装する。見出しのドラッグで移動し、閉じるボタンで閉じる。画面全体のカード・盤面を操作できるよう、透明な全画面要素で背面を遮断しない。カード詳細や既存の選択・確認UIによる操作遮断は維持する。
3. 1行1ダイスとし、左に3D外観、右に6面のアイコンを横並びで表示する。現在面、未使用／消費済み、永続／一時を識別可能にする。各面をタップすると通常面の色・画材、特殊面の効果をゲーム内の説明として表示する。
4. 左の3D外観は既存の形状・面表現を再利用し、現在面を上面に向けた固定姿勢で表示する。パレット上の姿勢・物理ロールへの常時追従は行わない。出目未確定時は未確定を示し、仮の上面を現在の出目として提示しない。
5. 外観のタップで既存の選択／解除へ接続する。選択の正本と許可条件は既存view.jsを利用し、パレット・リスト・達成可能表示を同期する。独自のゲームルール判定を増やさない。
6. 目標からの既存面検索に連携し、リスト内の該当面を色と枠などで強調する。次の検索で置き換え、閉じて開き直した時は解除する。開く前の検索結果は復元しない。パレット上の約3秒の検索表示は維持する。
7. 面変更、現在面確定、使用・再利用、獲得・回収などの状態更新を反映する。検索中の面変更・増減も現在の検索条件で再照合する。
8. パレット操作の550msの時間判定と長押し予約を削除する。保持時間によらず、移動量6 CSS px未満で押して離すと選択／解除する。一度でも6px以上動いた操作、キャンセル、キャプチャ喪失は選択しない。標準コンテキストメニューの抑止は維持する。
9. 多数のダイスはリスト内部で縦スクロールする。スクロールバーは世界観に合う独自外観とし、ブラウザ標準の外観を出さない。ホイール・タッチスクロールによる全行への到達を維持する。

## 対象外

- カード詳細を開いたままダイスリストを操作する対応。使いにくさの指摘があれば、オーナーの指示に従い別項目としてバックログへ登録する。
- ダイス獲得候補を含む他の効果UIの正式化、旧評価用ダイス一覧の生成廃止（MP40-14）、QA-01全体。
- ダイスの物理挙動、ゲームルール、面検索条件、パレットの拡大方式の変更。
- 共通部GameWorksOAKおよびオーナー管理の要求仕様の変更。

## 完了条件

- 全所持ダイスの6面と最新状態を確認でき、情報確認だけではゲーム状態を変更しない。
- 外観の上面と確定した現在面が一致する。重複する面も6面を省略せず表示する。
- 未使用の確定済みダイス等、既存条件で許される選択だけを受け付け、パレットとリストの双方向で選択表示が一致する。
- 通常面・特殊面、永続・一時、消費済み、面変更、増減、空リスト、多数ダイスを確認する。
- 検索で該当する個々の面が強調され、時間経過後も保持される。次の検索で更新され、再オープンで解除される。検索・説明・選択の操作が互いを意図せず発火させない。
- ダイアログをマウス・タッチで移動でき、A/B・画面回転・リサイズ・固定倍率変更後も見出しと閉じる操作が画面内に残る。内部スクロールを移動操作として扱わない。
- プレイエリア・手札・ストックのカードを参照でき、カード詳細は最前面となりリスト操作を抑止する。詳細を閉じるとリスト操作を再開できる。
- 標準スクロールバー・標準ツールチップ・不要なフォーカス移動等を出さず、内容への到達を維持する。
- 長押し予約をソース・仕様・検証から除去し、タップ・ドラッグ・リロール・達成の既存操作を維持する。
- 対象テスト、全テスト、本番ビルドの結果とオーナー検証の判断・対応を実装報告へ記録する。

## 実装方針

- `src/game/palettePresentation.js`と`src/game/view.js`の接続を起点とし、リストのDOM・移動・更新・破棄と3D外観描画を適切な小モジュールに分離する。
- `src/dice/geometry.js`、`icons.js`、`orientation.js`等の既存描画と面の対応を再利用する。各行にWebGLRendererや物理Worldを作らず、共有レンダラーからの描画などで資源を抑える。閉じている間の不要な描画を止め、終了・再開始で購読・描画資源・ポインタ処理を解放する。
- 正式ゲーム状態から面・現在面・使用状態を読み、演出用の一時的な外観をゲーム状態として流用しない。
- `faceConditions.js`等の既存面判定と、通常面・効果の説明資源を共用する。検索条件はリストの開閉寿命で管理し、パレットの表示期限と分離する。
- 操作可能範囲・前後関係は既存カード詳細、選択UI、リロール確認との組合せで確認する。標準のshowModal等は追加しない。
- docs/spec/10.dice_component.md、16.effect_common_ui.md、19.palette_operation.mdおよび必要な開発・画面仕様を更新する。バックログは長押し方式の廃止と対応内容を反映し、完了項目の削除はレビュー承認時に行う。

## 検証方針

- 複雑な入力判定・状態同期・検索保持・上面姿勢は実装に先立ちテストで仕様を定義する。既存drag.test.jsの長時間保持ケースを新しい選択仕様へ変更し、キャンセル・移動・操作ロックの回帰を確認する。
- 新モジュールに対応する実装テストを追加し、現在面と上面の一致を6面すべてで確認する。要求03の情報確認に対応する検証を追加する。
- 既存ブラウザー検証のダイス選択・ドラッグ・面検索・カード詳細を利用し、リストの開閉・ドラッグ・状態同期・検索保持／再オープン解除・全行スクロール・重なりを検証するスクリプトを追加する。
- A/B、マウス・タッチ、画面回転相当のリサイズ、固定倍率、動きを減らす設定で確認する。ブラウザー検証と実機確認は区別して記録する。
- 全テスト: `npm.cmd test`。本番ビルド: `npm.cmd run build`。実装終了草案前に両方を実行する。
- 既存の`http://127.0.0.1:3000/MyPalette/`を利用し、常用サーバーを停止・再起動・置換したり別サーバーを追加起動したりしない。表示版が一致しない場合は報告する。
- オーナー確認では移動・一覧の視認性・面の説明・カード詳細との併用・検索強調・選択操作・独自スクロールバーを操作可能な単位で提示し、一意のIDと確認バージョンを付けて判断を記録する。
