# v0.44 ダイスリスト実装報告

対象ブランチは`feature/v0.44-dice-list`、確認バージョンは`0.44.0`。

## 実装内容

- `diceList.js`・`diceListState.js`・`diceListPreview.js`で移動可能なモードレスの全6面表示を追加した。選択は既存の`view.js`へ委譲し、3D外観は既存の形状・面描画を共有レンダラーで描画する。
- パレットの入力から550msの時間判定を削除し、移動量・キャンセル・キャプチャ喪失・操作ロックで選択を制御する。
- 面の説明は`cardIcons.js`の共通ポップアップに接続し、面変更・削除・小窓の移動・閉鎖・倍率変更で解放する。
- 検索強調はオーナー変更指示により3秒間へ変更した。通常の検索と時間定数を共有し、現在面の緑枠と異なる金色の光で強調する。動きを減らす設定では脈動しない。
- ボタン表示を「ダイスリスト」に変更し、開閉トグルと開閉状態の表示を追加した。初回位置は中央とし、小窓の色・枠・影をカードから区別する表現に変更した。状態の文字行、現在面の下線、常設の説明欄は削除した。

## 追加フィードバックへの対応

- 使用済みダイスは6面のCanvasをグレー表示し、再利用時に色を戻す。ChromeのA/Bで全6面・説明操作・色の復帰を確認した。
- セパレータは行同士の間だけに表示し、末尾の下には表示しない。
- ダイスリストの閉じるボタンをX印に変更した。共通の符号パスと合成・実測輪郭を利用するcontrolIconCanvasを追加し、レビューIDcontrol-closeで共通確認画面へ登録した。開閉とトグル状態の同期、2背景・3サイズを確認し、checkCommonIcons.cjsは137ケース・411描画で空画像・欠け・エラーなし。本番ビルドも成功した。これらの追加対応も、後の「スクロールだけ未確認」とのオーナー判断で確認済み。

- X印のホバー時の視認性は、個別の配色調整を追加せず共通の`ControlIcon`クラスで対応した。共有描画をマスクにして`currentColor`で描き、Chromeで通常・ホバー・押下のすべてでボタンの文字色と一致すること、ホバー時に明るいX印へ変わること、閉じる操作を確認した。本番ビルドも成功。

- 共通`ControlIcon`への変更後、「Xが全く見えなくなった」との報告があった。最新のゲーム実入口・本番成果物では通常／ホバー時とも表示を確認し、追加のコード変更は行わなかった。オーナーから「再読み込みで見えるようになった」と回答を受領したため、非表示の報告は解消として記録する。更新途中の表示だった可能性はあるが、原因を特定済みとは扱わない。

- DL44-08：将来の獲得セクションに備え、所持ダイス一覧を共通の`FramedSection`で包んだ。枠なしでも1pxの透明枠と6pxの内側余白を確保し、`state-framed`は色だけを変更する。確認ページに「セクション枠切替」を追加。`node scripts/checkDiceListSection.cjs`はChromeの1200×844・390×844、倍率0.7／1／1.25、3／30／0個で、枠の有無による窓・行・面の座標／寸法とスクロール範囲の不変を確認して成功。枠あり／なしの画像も確認した。v0.44.0の確認ページに対するオーナーの「okです。」を受領し、本項目は確認済み。獲得候補の見出しは「獲得永続ダイスの選択／獲得一時ダイスの選択」へ変更する指示をバックログへ反映した。

## リスト記号の共通化とスクロール確認ページ

- ダイスリストボタン左の記号は、オーナーの修正指示に基づき`drawListSymbol`・`controlIconCanvas`・`ControlIcon`へ共通化した。100単位座標・共通main寸法・実測輪郭を使用し、共通確認画面へ`control-list`として追加した。線幅は当初3とし、追加指摘で6へ変更した。`checkCommonIcons.cjs`は138ケース・414描画で成功。最終の太さはオーナー確認済み。
- スクロール確認ページは、Chromeの1200×844と390×844で自動的に30個を用意して開くことを確認した。Aではホイールで末尾へ到達。Bでは端末エミュレーションの合成スワイプで途中へ移動し、ホイールで末尾へ到達して状態表示も更新されることを確認した。合成スワイプはイベント間隔35msで実行。保存済み設定は変更しない。

- スクロールバーがほとんど標準に見え、ゲームのスタイルに合わないとのフィードバックを受領。ネイティブバーへの色付けを廃止し、共通`ScrollBar`／`ScrollThumb`で深緑のつまみ・淡い緑の溝・グリップを持つ独自部品に変更した。`node --test tests/implementation/ui/scrollBar.test.js`は寸法・最小つまみ・両端／途中・内容が収まる場合で2件成功。`node scripts/checkDiceListScrollbar.cjs`はChromeの1200／390px、倍率0.7／1.25で、つまみドラッグ・溝クリック・ホイール・タッチ・末尾到達・空リストの検証に成功。後続のオーナー再確認をDL44-06へ記録した。

- CSSスタイルガイドに従い、スクロールバーの形状・配置は`ScrollBar`／`ScrollThumb`、質感は汎用の`texture-recessed`／`texture-painted`、状態は`state-inactive`／`state-dragging`へ分離した。質感は使用箇所が`createScrollBar`の`trackTexture`／`thumbTexture`で指定し、共通操作処理は特定の質感名を固定しない。別の`texture-paper`／`texture-label-inverse`でも生成とスクロール同期が動くことを確認。A/Bの操作検証、全264テスト、本番ビルドも成功。

- ダイアログのスタイルも共通規約に従って整理した。`DiceList`側は配置・寸法・枠幅・重ね合わせ形状に限定し、文字色・面色・区切り線・選択／現在面の色・検索の光・グレー変換を共通の`texture-*`と`state-*`へ分離した。`texture-window`／`--ui-window-surface`は用途を小窓へ固定しない`texture-tinted`／`--ui-tinted-surface`へ改名。枠形状と枠色、単色アイコンの形状と塗りも分離した。整理前に`node scripts/dev_checkDiceListStyle.cjs --record`相当で基準を記録し、整理後の比較はA/Bの通常・選択中・使用済み・現在面・検索強調の色／寸法が基準と一致して成功した。比較用スクリプトと基準JSONは開発中の一時成果物とする。
