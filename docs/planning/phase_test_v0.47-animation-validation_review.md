## 計画との照合

- ［着手］はrecord.areaがhandになるまでhidden。CardScene.moveは個別のprogressForが1になったフレームで所属をhandへ更新し、その描画後にfollowを呼ぶ。待機・飛行中と到着済みを区別できる。
- hand.cssは既存のdisplay:flex指定より詳細なhiddenセレクターで表示を抑止する。演出中のinert、離れるカードの操作撤去、残る手札の追従・既存固定倍率変換を維持する。
- checkHandActionFollowは修正前の失敗を報告し、日次4枚・効果2枚・山札残1枚、個別到着と最後のカードの終了時確認を追加。Reduced条件も含む。
- checkCardSceneは個体・所属・有限姿勢・操作遮断に加え、終了後の全カード行列と所有者解放を確認。stressは21種類の演出を通し、A/B幅・高さ・倍率・開閉を変更する。
- ボード合成fixtureのclearは操作欄だけを除去し、実カードの一意性確認を維持する。通常ゲーム側へのエラー隠蔽処理追加なし。
- MP47-01/02の確認済みは実装報告のオーナー回答記録を根拠とする。独立した実装チャット全文の再取得は行っていない。
