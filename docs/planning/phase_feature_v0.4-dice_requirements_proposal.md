# ダイス表示に関する要求仕様の修正許可

オーナーは、以下の2箇所の変更を明示的に許可した。
配置・配色・画像合成・演出の詳細は docs/spec/10.dice_component.md で扱う。
docs/requirements/02.visual.md は変更しない。

## R1: docs/requirements/04.effect_conventions.md 3.4末尾

修正前:

> 画材記号は、効果アイコンと実際のダイス面の左肩に表示する視覚補助記号で共通して使用する。
>
> 実際のダイス面の中央に描く画材そのもののアイコンは、この記号とは別に維持する。

修正後:

> 画材記号は、効果アイコンと実際のダイス面で共通して使用する。

理由: 記号を共通利用する要求を残し、具体的な配置と中央画像の維持指示を除く。

## R2: docs/requirements/05.icon_presentation.md 2.4の箇条書き

修正前:

> * ダイス面の左肩にある視覚補助記号

修正後:

> * ダイス面にある画材記号

理由: 共通記号の使用箇所を示す要求を残し、具体的な位置指定を除く。

## 即時リロールの雷追加案

オーナーの「リロールアイコンの右に雷アイコン」を受けた変更案。要求仕様はまだ変更していない。

1. 06.dice_effects.md 3.1 アイコン表現の冒頭：
   前：即時リロールのアイコンを、長方形のチケットの内部に配置する。
   後：リロール図形を、長方形のチケットの内部に配置する。
   理由：チケット内には即時を表す雷を含めず、共通のリロール図形を使う。
2. 06.dice_effects.md 3.2 アイコン表現の末尾：
   前：この効果では、リロール権のチケットを使用せず、即時リロールのアイコンを直接表示する。
   後：この効果では、リロール権のチケットを使用せず、リロール図形の右に雷マークを配置して即時の処理であることを表す。
   理由：即時の意味を雷で示すという指示を反映する。直前のチケット内の共通図形の説明は維持する。
3. 05.icon_presentation.md 3節の表の項目名：
   前：即時リロール
   後：リロール図形
   理由：同じ行の「傾いた六角形＋右肩の波紋」は共通図形の定義として維持し、雷の意味を06の説明に集約する。
