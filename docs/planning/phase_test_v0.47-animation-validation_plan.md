# v0.47 演出検証と手札操作表示の是正

## 合意事項

- 対象バックログ: MP40-15「演出の検証（二重表示・操作競合・座標・追従）」。
- 追加指摘: ドロー時の［着手］ボタンの表示が早すぎる。手札にあるときだけ表示する。
- 予定バージョン: `0.47.0`。実装開始時にpackage.jsonとpackage-lock.jsonを更新する。
- ブランチ: `test/v0.47-animation-validation`。
- 開発内容へのオーナー合意: 2026-11-28のチャット。

## 開発スコープ

カードの初日配分・ドロー・着手・達成・出荷・捨て札への移動・ストック操作・山札再構成について、既存の検証を点検し、不足する検証を追加する。二重表示、操作競合、画面外からの移動、座標と配置変更への追従、終了後の表示・操作復帰を対象とする。対象内で発見した不具合は修正し、再現条件と回帰確認を記録する。

ドロー対象の［着手］ボタンは、ゲーム状態への先行追加だけで表示せず、表示上も手札への移動を完了してから通常の着手条件に従って表示する。日次ドローと効果による複数枚ドローを含む。着手で手札を離れるカードのボタン撤去と、残る手札のボタン追従・操作遮断を維持する。

- 要求仕様の変更、ゲームルール・カード設定の変更。
- GameWorksOAK共通部の変更。
- 本番・preview公開、masterへのマージとpush。

## 完了条件

1. 各対象経路で実カードのID・DOMの一意性と枚数を維持し、移動元・移動中・移動先の二重表示がない。
2. 演出中に進行操作が競合せず、終了後に必要な操作が復帰する。ゲーム状態と演出の順序、後続処理の一度だけの再開を維持する。
3. 画面外の移動元を含む経路で座標が妥当で、終了時のカード・イーゼル・操作要素が所定の配置へ到着する。意図した画面外配置を誤って不具合扱いしない。
4. A/B、狭い縦横画面、演出中のリサイズ・パネル開閉・固定倍率変更について、移動と終了後の配置が追従する。
5. 動きを減らす設定でも同じ所属変更と最終状態を保ち、演出や操作待ちが残らない。
6. 日次・効果ドローの待機中・移動中のカードに［着手］ボタンを表示しない。表示上の手札への到着後に表示し、複数枚ドローでは各カードの到着を基準に扱う。演出全体による操作ロックは維持する。
7. 検証条件・結果・未検証範囲とオーナー検証の判断を実装報告に記録する。全テストと本番ビルドを実行し、失敗があれば共通手順に従って調査・対応する。

## 実装・検証方針

- `docs/spec/13.area_transition.md`、`18.card_scene.md`、関連する手札・ストック・プレイエリア仕様と実装を照合し、対象経路と条件の対応表を実装報告へ記録する。
- `cardScene`、`cardScenePlans`、`cardSceneTimeline`、`handPresentation`、`gameCardActions`のゲーム状態と表示上の所属・移動完了の扱いを調査する。手札への到着判定を描画姿勢の偶然の一致や待ち時間に依存させない。
- 複雑な状態管理やイベント連鎖の修正は、再現するテストを先に作成する。単体テストは対応ソースの配置と責務に従う。
- `checkCardScene.cjs`、`checkCardSceneReduced.cjs`、`checkCardSceneLimits.cjs`、`checkBoardMotion.cjs`等を活用し、不足を補う。各条件を全経路の直積で繰り返すのではなく、共通処理と経路固有の境界を区別し、選定根拠を記録する。
- `checkHandActionFollow.cjs`はドロー中のボタン追従を前提にしているため、その前提を改める。日次・複数枚効果ドローで到着前の非表示と到着後の表示をカードID単位・フレーム単位で確認し、残る手札の追従、着手開始時の撤去、操作遮断を引き続き検証する。
- `18.card_scene.md`の「日次・効果ドローでは対象カードの現在位置から追従」という記載と検証説明を、合意した到着後表示に合わせて更新する。関連する実装仕様・開発手順も必要な箇所だけ更新する。
- ブラウザー検証は既存の `http://127.0.0.1:3000/MyPalette/` を使用する。常用サーバーを停止・再起動・置換せず、追加サーバーを起動しない。接続不能や表示版の不一致は報告する。
- 実装終了草案の前に `npm.cmd test` と `npm.cmd run build` を実行し、結果を記録する。Chromium検証とSafari実機検証は区別する。
- オーナーには、日次・効果ドローの［着手］表示タイミングと、代表的な移動・配置変更後の見た目を確認項目として提示し、判断・フィードバック・明示的な保留を記録する。
