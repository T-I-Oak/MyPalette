# v0.8.0 ストックの即時公開の実装報告

## 実装結果

- チラシによる発注、カード効果、手札交換で共用する取得処理で、カードを取り除いた直後に同じグレードの先頭を公開する。空になれば公開カードなしとする。
- 複数枚の取得では直前に公開されたカードを次の候補に含める。ターン終了時には、その時点で公開中のカードを一番下に送る。
- 承認済みの要求仕様3か所を改訂し、評価用ゲームの実装仕様も更新した。バージョン設定は `0.8.0`。

## 検証結果

- 関連テスト19件が成功。連続取得、ストックが尽きた場合、空のストックへの返却、ターン終了時の入れ替えを確認した。
- `npm.cmd test` はサンドボックス内でローカル接続と一時ファイル置換が制限された。サンドボックス外で再実行し、全121件が成功した。
- `npm.cmd run build` が成功した。
- Edgeのヘッドレス実行で開発者用入口のバージョン表示を確認した。ブラウザーにだけ2枚取得効果を設定したカードデータを渡し、評価用ゲームの選択画面でB09、続けてB04を取得した。公開ストックにB14が表示され、ページエラーは発生しなかった。

## オーナー検証

- `MP-08-01` の依頼は取り下げた。取得直後の公開と表示更新は合意済みの仕様に対して客観的に判定でき、関連テストとEdgeでの画面操作で確認済みのため、追加のオーナー検証は不要と判断した。
