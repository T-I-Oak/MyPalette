# カンバス支持・固定の実装報告

## 対象と実装結果

- MP45-01「達成演出のカンバスを上部固定具で支える」。バージョンv0.46.0、ブランチ`fix/v0.46-canvas-support`。
- 実装開始後、オーナーから「固定サイズなので基本的に固定位置でいいはず」と指示を受け、現行1536×1024の固定寸法に対象を絞った。正方形・縦長への寸法追従、支柱の伸縮、撤去時の位置復元は追加していない。計画書にこの指示による絞り込みを記載した。
- `createEasel.js`で、現行寸法を`canvasPlacement(1536, 1024)`に渡した上端へ押さえ下面を固定した。ブロック下面を押さえ上面へ、つまみ背面をブロック前面へ合わせた。
- 受け台・支柱・脚・カンバス形状・通常カードの投影・演出の時間と順序・設置撤去APIは変更していない。固定具は常設なので、カンバスを撤去・再設置しても同じ位置を保つ。
- `package.json`と`package-lock.json`を0.46.0へ更新し、`docs/spec/15.play_area.md`へ固定寸法での接触と座標系の契約を記載した。
- 要求仕様・保存済みカード設定・絵画素材・GameWorksOAK共通部は変更していない。公開・マージ・pushは実施していない。バックログのMP45-01はレビューの削除承認前なので維持している。

## 接触の数値と画像

検証環境はWindows、headless Microsoft Edge 158.0.4370.33、DPR 1。既存`http://127.0.0.1:3000/MyPalette/`を使用した。常用サーバーの停止・再起動・置換や追加の常駐サーバー起動は行っていない。通常タイトル下部の表示が`v0.46.0`であることも確認した。

### 製品部品の正面・左右と拡大

`scripts/checkAcceptanceCanvasSupport.cjs`で保存済みA01-1（1536×1024）を製品の`createPaintingCanvas`・`createEasel`・`mountCanvas`・`orientPainting`で表示した。通常向きへ水平角−0.4・0・＋0.4ラジアンを加え、各400×640の全体像と400×280の支持部拡大を取得した。全体カメラは製品と同じ投影・上50/下70の切り出しで、拡大だけ注視点を上端へ移してzoom 4を使った。

| 測定項目 | 結果（イーゼル前面のローカル単位） |
| --- | --- |
| カンバス上端／押さえ下面 | ともに1.6041666666666667、差0（変更前の差は約0.121833） |
| 下端−受け台上面 | 約1.11×10^-16 |

押さえは、面取りより内側の平らな上面を覆い、前端より0.015前まで届く。背面側は既存の支柱へブロックを介してつながる。画像でも3方向の接触を確認した。証拠は`tmp_acceptance_evidence/d03-canvas-support.png`と同名の`.json`。

### ゲーム本体の各ステップとA/B

`scripts/checkCanvasSupportMotion.cjs`で製品のゲーム接続・達成タイムラインを実行した。検証ブラウザー内だけ効果を空・目標をダイス1個・開始ステップを指定した。`createEasel.js`のHTTP応答へ観測用の参照公開を挿入し、実際に描画する個体を毎フレーム測定した。製品のfadeOut・repaintの終了後だけ観察待機を挟み、変更前後の画像を取得した。通常時の時間・順序の回帰は待機を挟まない既存の`checkCardScene.cjs`でも別途確認した。

## オーナー検証

- ID：MP45-01。
- 確認バージョン：v0.46.0（package設定と既存サーバーのタイトル表示が一致）。
- 理由：上端の支持が自然に見えるかは数値だけでは判断できないため。
- 提示内容：チャットに正面・左右の全体と支持部拡大画像を提示し、「上部固定具がカンバス上端を自然に押さえて見えるか」を確認依頼した。
- オーナーの判断：**項目確認済み**。
- 対応：判断を本報告へ記録。見た目の修正指摘・未回答項目はない。要求・バグ台帳のMP45-01の削除判断はレビューで行う。

## 検証の限界

現行の固定寸法のみを対象とし、正方形・縦長など別比率への対応は今回のオーナー指示により対象外。Edgeの検証をSafari等の実機確認とは扱わない。CARD-01のカード可読性・接地感、MP40-09のカードとカンバスの絵の一致、MP40-15の演出全般は対象外。新しい常駐検証サーバーは起動していないため停止対象はない。
