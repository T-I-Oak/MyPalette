# v0.7.4 エリア間移動のレビュー

## 未解決の指摘

1. **エリアの倍率がDOM要素の中身に適用されない。** `src/ui/areaTransition/createDomTransitionSurface.js` はラッパーの位置・幅・高さを更新する。既定の `MoveObject.render()` は空なので、仕様書のボタン例のように幅・高さを100%にしても、固定ピクセルで指定した文字・余白・子要素の寸法は倍率に追随しない。異なる倍率のエリアを移動すると、外枠だけが変わり、中身ごと拡縮するという合意を満たせない。共通倍率・エリア倍率・移動中の寸法変化が固定寸法の中身にも反映されることをDOM上で確認する。
2. **山札を表示した状態でもドローが画面外から始まる。** `src/game/view.js` は描画を更新する前に移動元を取得するが、`src/game/areaTransitions.js` の `captureCard` はカードIDを持つ表示要素だけを探す。表示中の山札には枚数のアンカーしかなく、アンカーは到着側でしか参照されない。「ストック・山札・捨て札」を開いたまま「翌日の仕事を始める」を押しても、カードは常に画面右の外から現れる。タブ表示中は更新前の山札位置、非表示時は画面外の位置を使うことを確認する。
