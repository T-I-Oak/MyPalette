## 実装結果

| 計画項目 | 実装 |
| --- | --- |
| 全体更新ボタン | `view.js` で未使用ダイスの選択がゼロまたは全数の場合に有効とした。選択待ち・通知・演出中と、リロール権または未使用ダイスがない場合は無効にする。振り直しは既存の全体リロール処理を使う。 |
| エリア移動時のStepタブ | `cardScene.js` の表示内容とタブ選択をエリア・制作ステップに対応させた。移動時は現在のStepを表示し、同一エリア・同一Stepでの再配置では選択を保持する。 |
| カード効果の名声変更 | `engine.js` でプレイ時・達成時それぞれの名声変更を先に解決する。通知はカードの記載順で表示する。 |
| 日末の「名声値＋1」 | 消費する特殊面を日末の名声変更と翌朝予約に分けた。継続時は手札・場の回収とストックをしまう演出の完了を待ち、終了時は最終結果の記録前に名声を反映する。 |
| 翌朝の予約取得ダイス | `effects.js` の取得処理を共用し、翌朝は新規ダイスを未確定のまま追加して開始ロールに含める。プレイ中の取得は獲得分のみを振る。 |

- 全テスト `npm.cmd test` は215件成功。サンドボックスでの再実行では既存の保存APIテスト2件がローカル接続の `EACCES` と保存時の HTTP 500 で失敗した。通常のローカル環境で同じコマンドを再実行し、2件を含めて成功を確認した。
- 本番ビルド `npm.cmd run build` は成功。
- Edge のブラウザー検証では、開発サーバー上の一時検証ページ `tmp_v024_browser.html` を使用した。物理ロールの返却値を固定して、全体更新ボタンの有効条件と対象、権利消費、同一エリアのStep保持、手札からプレイエリアへの移動開始時と着地後のStepを通常演出と省略設定で確認した。省略設定では日末の名声表示、翌朝の候補選択、既存分と獲得分を含む1回の開始ロール要求、最終日の名声表示も確認した。

## オーナー検証

以下はすべて `0.24.0` で確認する。日末・翌朝用の一時確認ページは、開始時のダイス構成と終了日ケースの信用をページ内だけで調整する。ロールは実際の物理演出を使う。

| ID | 確認理由・操作 | 期待結果 | 判断 |
| --- | --- | --- | --- |
| V024-01 | 実ロールとの接続を確認する。ゲーム本体で仕事を始め、未使用ダイスをゼロ・一部・全数の順に選択して、全数選択で「すべての画材を更新する」を押す。 | ゼロ・全数で有効、一部で無効。未使用ダイスをすべて振り直し、リロール権が1回減る。 | 確認済み |
| V024-02 | 実際の速度でタブの切り替わりを確認する。手札で現在と異なるStepタブを開き、同じカードの「着手」を押す。 | 移動中から着地後まで現在のStepを表示する。 | 確認済み |
| V024-03 | 名声の表示時点と翌朝の物理演出を確認する。`tmp_v024_review.html` で仕事を始め、そのまま終え、翌日を始めて獲得候補を1つ選ぶ。 | 片づけ中は名声0で、ストックをしまうまでの全演出が終わってから名声2を表示する。候補確定後に既存3個と獲得1個をまとめて1回振り、名声は2のまま。 | フィードバック対応済み。加算時点はブラウザーテストで確認したため、オーナーによる再確認は不要。 |
| V024-04 | ゲーム終了時の表示を確認する。`tmp_v024_review.html?final` で仕事を始め、そのまま終える。 | 信用0で終了し、最終名声に当日分2を含める。 | 確認済み |

V024-03 では「ストックをしまうなど、すべての片づけが終わったら名声を加算」とフィードバックを受けた。カード移動とストックの収納を終えてから日末の名声効果を再開するよう変更した。修正後は `node --test tests/implementation/game/dayStart.test.js tests/implementation/game/engine.test.js` の14件、`npm.cmd test` の215件、`npm.cmd run build` が成功した。

出目を固定した Edge の通常演出で、カード回収、ストックを裏返す処理、ストックをしまう処理の各開始時点で名声0を確認した。収納完了後、翌日の開始待ち画面では名声2が表示された。

達成時の獲得効果の表示順について追加の指摘を受けた。プレイ・達成の通知をカード記載順に戻し、名声の先行解決と選択待ちからの再開を検証した。対象テスト `node --test tests/implementation/game/engine.test.js tests/implementation/game/effectNotices.test.js` の18件、`npm.cmd test` の215件、本番ビルド `npm.cmd run build` が成功した。
