# v0.26 タイトル画面とゲーム終了後の遷移

- 予定バージョンは `0.26.0`。実装開始時に `package.json` と `package-lock.json` を更新する。
- 開発ブランチは `feature/v0.26-title-and-results`。

## 開発範囲と完了条件

1. `/MyPalette/` を開くと、タイトル画面にゲーム名、`package.json` に基づくバージョン、「ゲームを始める」を表示する。開始操作で保存済み設定を読み込み、検証に成功すると初日の仕事開始待ちへ進む。読み込み・検証に失敗した場合は理由を表示し、再試行できる。
2. 信用が 0 になった日の終了処理が完了した時点で、簡素な仮のゲーム終了画面を表示する。ゲームの終了が分かり、タイトルへ戻れることを確認する。信用が残る日は翌日の仕事開始待ちへ進む。
3. 仮のゲーム終了画面の「タイトルへ戻る」からタイトル画面へ移動でき、再度ゲームを始めると初日の状態から進行できる。

## 対象外

- 実機検証用の GitHub Pages 公開。
- ゲーム終了画面の正式化。最終名声値の表示は正式化の完了条件として扱う。
- 過去の自己記録の保存と比較。
- ゲームルールの変更。

## 実装方針

- `src/main.js` でタイトル、設定読み込み、ゲーム、結果の画面遷移を管理する。バージョン表示には既存の `initializeAppVersion` を使い、設定の読み込みと検証には `loadSettings` と `gameIssues` を使う。読み込み中は開始・再試行の重複操作を防ぐ。
- ゲーム側は日末の演出と名声値の加算が完了し、エンジンが `finished` になったことを入口側へ通知する。既存の破棄処理を使ってゲームと表示の資源を解放する。再開始時は新しいゲームを生成する。
- `docs/spec/09.playable_game.md` と `docs/01.development.md` に画面遷移と操作手順を反映する。

## 検証方針

- ブラウザーで、バージョン表示、開始操作、設定エラーと再試行、日末処理完了後の仮画面表示、タイトル復帰、状態を引き継がない再開始を確認する。信用が残る日は翌日に進めることも確認する。
- ゲーム画面から結果画面への遷移と再開始をレイアウト A/B で確認する。既存の起動・画面配置の検証は、タイトルでの開始操作を経由するよう必要な箇所を更新する。
- 実装中にタイトルと結果画面の表示案、確認可能な操作手順をオーナーへ提示し、判断と対応を実装報告に記録する。
- `npm.cmd test` と `npm.cmd run build` を実行し、本番プレビューの `/MyPalette/` で起動経路を確認する。
