# My Palette 効果共通仕様

## 1. 目的

本書は、My Paletteに登場する効果に共通する規則と、効果を視覚的に伝えるためのアイコン体系を定義する。

効果アイコンは、プレイヤーが効果の説明文を読まなくても、その内容を理解できることを目指す。

そのため、本書ではアイコンを構成する図形、記号、それらの組み合わせ方を定義する。

アイコンの視認性や描画上の調整事項は「My Palette アイコン表示要求仕様」で定義する。

---

## 2. 効果の共通規則

### 2.1 効果の発動

本書で定義する効果は、カードの効果や特殊面の効果などから共通して利用する。

効果そのものには、発動タイミングを含めない。

カードのプレイ時、目標達成時、ターン開始時などの発動タイミングは、その効果を使用する側のルールに従う。

### 2.2 アイコンの基本原則

効果アイコンは、共通の意味を持つ視覚要素を組み合わせて表現する。

特に、ダイスとダイス面に関するアイコンは、以下の原則に従う。

* **外側の図形**によって、対象がダイスなのか、ダイス面なのかを表す。
* **塗り色と文字**によって、指定する色を表す。
* **画材記号**によって、指定する画材を表す。

同じ意味の視覚要素は、異なる効果でも共通して使用する。

---

## 3. アイコンの基本図形

### 3.1 基本図形

| 対象     | 基本図形                   |
| ------ | ---------------------- |
| ダイス    | 六角形                    |
| ダイス面   | 45度傾けた角丸正方形（以下「ひし形」）   |
| 個別のカード | 長方形                    |
| 手札     | 扇形に広げたカード              |
| ストック   | やや傾いた長方形のカードを縦に積み重ねた図柄 |
| 名声     | 月桂冠                    |
| 特殊面全体  | 星型                     |

六角形は、基本的にダイスそのものを表す。

ひし形は、ダイスの面、または面に指定する属性を表す。

ストックアイコンは、ストック専用の記号として使用する。

### 3.2 色の表現

色を指定するアイコンでは、指定色で図形を塗りつぶし、その内部に対応するアルファベットを白抜きで配置する。

色と文字の対応は以下のとおりとする。

| 色 | 文字 |
| - | -- |
| 橙 | O  |
| 黄 | Y  |
| 緑 | G  |
| 青 | B  |
| 紫 | P  |
| 赤 | R  |

塗り色と文字の両方によって色を識別できることを目指す。

白抜き文字が背景に埋もれないよう、必要に応じて縁取りなどを使用できる。

### 3.3 補色の組み合わせ

色を2色指定する効果では、次の3組を使用する。

| 組み合わせ | 色文字 |
| ----- | --- |
| 赤・緑   | R・G |
| 橙・青   | O・B |
| 黄・紫   | Y・P |

これらは、My Paletteの6色を色相環に等間隔で配置した場合に、向かい合う色の組み合わせである。

補色を採用することで、組み合わせを自然に3パターンに限定できる。

また、色相の異なる2色を併記することで、小さなアイコンでも両者を識別しやすくする。

2色を指定するアイコンでは、基本図形の内部を2色に分け、それぞれの色領域に対応する白抜き文字を配置する。

### 3.4 画材の表現

画材の指定には、画材に由来する3種類のシルエット記号を使用する。

| 画材    | 記号の形状        | モチーフ      |
| ----- | ------------ | --------- |
| 絵筆    | 先端の尖ったしずく形   | 筆先        |
| パステル  | 角丸の平行四辺形     | パステルの棒状の形 |
| エアブラシ | 3つの丸がつながった雲形 | 丸い吹き付け跡   |

これらの記号は、単純な輪郭によって互いを識別できる形状とする。

画材記号には、特定の色を指定しない場合と、色を指定する場合がある。

**画材のみを指定する場合**

画材記号を黒などの無彩色で表現する。

**色と画材を同時に指定する場合**

画材記号を指定色で塗り、その内部に対応する白抜きアルファベットを配置する。

画材記号は、効果アイコンと実際のダイス面の左肩に表示する視覚補助記号で共通して使用する。

実際のダイス面の中央に描く画材そのもののアイコンは、この記号とは別に維持する。

### 3.5 ダイスとダイス面の属性表現

ダイスまたはダイス面の属性は、以下の共通ルールによって表現する。

| 指定内容     | アイコン表現               |
| -------- | -------------------- |
| ダイス      | 六角形                  |
| 面        | ひし形                  |
| ダイス＋色    | 指定色で塗られた六角形＋内部の白抜き文字 |
| ダイス＋画材   | 六角形＋内部の画材記号          |
| ダイス＋色＋画材 | 六角形＋内部の色付き画材記号＋白抜き文字 |
| 面＋色      | 指定色で塗られたひし形＋内部の白抜き文字 |
| 面＋画材     | ひし形＋内部の画材記号          |
| 面＋色＋画材   | ひし形＋内部の色付き画材記号＋白抜き文字 |

色を2色指定する場合は、六角形またはひし形の内部を指定された補色2色に塗り分け、それぞれの領域に白抜き文字を配置する。

「ダイス＋色＋画材」と「面＋色＋画材」は、現時点では効果として使用する予定がない。

ただし、アイコン体系としては表現可能な構成とする。

### 3.6 一時ダイスの表現

永続ダイスは、基本となるダイスアイコンで表現する。

一時ダイスは、ダイスアイコンの外側に補助記号を付けて区別する。

補助記号は、六角形の左右を雲の縁のようなマークで囲む表現を基本とする。

概念的には、以下の構成とする。

`(( [ダイスアイコン] ))`

### 3.7 変更操作の表現

対象を書き換える効果には、ペンアイコンを使用する。

ペンアイコンの後に、変更後の状態を表すアイコンを配置する。

* ダイス面の変更：ペン＋変更後の面を表すひし形
* カードのステップ変更：ペン＋変更後のステップを示すカード

### 3.8 特殊面の表現

特殊面の共通記号には、星型を使用する。

特殊面全体をまとめて指す場合は、星型を使用する。

一方、特定の特殊面を指定する場合は、その特殊面が持つ効果のアイコンを使用する。

具体的な効果を示すアイコンに、星型を重ねる必要はない。

### 3.9 カードの移動に関する表現

カードのドローとストックからの獲得には、カードを表すアイコンと左向き矢印を組み合わせる。

| 効果           | アイコン構成          |
| ------------ | --------------- |
| ドロー          | `[手札] [←] ＋N`   |
| ストックからのカード獲得 | `[←] [ストック] ×N` |

手札アイコンは扇形に広げたカード、ストックアイコンはやや傾いた長方形のカードを縦に積み重ねた図柄とする。

## 4. 数値の表現

### 4.1 基本原則

効果アイコンに付随する数値は、対象が増減する数量を表すか、物の個数や処理回数を表すかによって使い分ける。

基本的な考え方は、**単体を表すアイコンには「×N」、集合や数量を持つ状態を表すアイコンには「＋N／−N」**を使用することである。

ただし、効果ごとの具体的な表記を優先する。

### 4.2 増加

数量や状態の増加を表す場合は、`＋N` と表示する。

`＋1` は省略しない。

### 4.3 減少

数量や状態の減少を表す場合は、`−N` と表示する。

`−N` は赤文字で表示する。

`−1` は省略しない。

### 4.4 個数・回数

物の個数や処理回数を表す場合は、`×N` と表示する。

`×1` は省略できる。

### 4.5 各効果への適用

| 効果           | 数値表現              |
| ------------ | ----------------- |
| 名声値の変更       | `＋N／−N`           |
| ダイスの獲得       | `×N`              |
| リロール権の獲得     | `×N`              |
| カードのドロー      | `＋N`              |
| ストックからのカード獲得 | `×N`              |
| 手札交換         | `×N`              |

数値表記だけで効果のすべての意味を表そうとせず、アイコンと数値を組み合わせた全体で意味を伝える。
