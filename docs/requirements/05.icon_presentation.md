# My Palette アイコン表示要求仕様

## 1. 目的

本書は、My Paletteの効果アイコンについて、視認性、表示の一貫性、描画上の調整事項を定義する。

アイコンを構成する図形や記号の意味は「My Palette 効果共通仕様」で定義する。

---

## 2. アイコンの表示に関する要求

### 2.1 効果の識別

効果アイコンは、プレイヤーが効果の処理内容を理解できることを目的とする。

効果の種類、変更対象、指定された属性、数量などを識別できること。

複数の視覚要素を組み合わせる場合も、それぞれの意味が読み取れること。

### 2.2 複合アイコンの視認性

カードの効果を確認する表示状態では、効果共通仕様で定義する複合アイコンを識別できる大きさで表示する。

特に、以下を組み合わせたアイコンを識別できる必要がある。

* ペン
* ダイス面を表すひし形
* 一時ダイスの補助記号
* ダイスを表す六角形
* 画材記号

この組み合わせを、カードの表示領域や視認性を検討する際の基準の一つとする。

カードを縮小表示している間にすべての構成要素を判読できる必要はないが、プレイヤーが効果を確認する際には、識別可能な表示状態を提供する。

### 2.3 色と記号の視認性

色の指定では、塗り色だけでなく白抜きアルファベットも識別できること。

補色2色を指定する場合は、2色の領域と、それぞれに対応する文字を識別できること。

画材の指定では、3種類のシルエット記号を識別できること。

特に、先端の尖ったしずく形と、3つの丸がつながった雲形が、小さな表示でも混同されないこと。

また、画材記号の中に色文字を配置する場合は、記号の輪郭と文字の両方を識別できること。

### 2.4 共通の視覚表現

同じ意味の要素には、共通のアイコンを使用する。

特に、画材記号は以下の場所で共通して使用する。

* ダイス面にある画材記号
* 画材指定ダイスの獲得アイコン
* ダイス面の画材変更アイコン
* その他、画材を指定する効果アイコン

リロール権の獲得では、効果アイコンとゲーム画面上の所持リロール権に共通のチケット表現を使用する。

これにより、プレイヤーが一度理解した記号を、別の場面でも利用できるようにする。

ダイス破棄のアイコンは、ダイスとゴミ箱の両方を識別でき、ダイスの獲得やターン中の消費と混同しないこと。

### 2.5 小さな表示への対応

効果アイコンは、小さな表示での識別性を考慮して設計すること。

特に、ダイス面に表示する効果アイコンについて、縮小時にも効果の種類を識別できること。

カード上では、効果の内容を確認するために十分な表示サイズを確保できること。

### 2.6 アイコンの調整

具体的な線の太さ、余白、色調、記号の細部、表示寸法などは、視認性を確保できる範囲で調整できる。

ただし、アイコンの識別に必要な構成要素と、その意味は維持する。

定義されたアイコンを識別可能な状態で表示できない場合は、表示方法やアイコンの構成を再検討する。

---

## 3. 描画上の調整事項

以下は、基本的なアイコン構成は定義されているが、具体的な描画方法を調整できる事項である。

| 項目       | 定義済みの方向性                  | 調整できる内容         |
| -------- | ------------------------- | --------------- |
| 画材記号     | しずく形・角丸平行四辺形・三つの丸がつながった雲形 | 輪郭の細部、縦横比、余白    |
| 色文字      | 指定色の内部に白抜きのO/Y/G/B/P/R    | 文字の太さ、縁取り       |
| 補色2色の指定  | 六角形・ひし形を2色に塗り分け、各領域に文字を配置 | 領域の分割方向、比率、文字配置 |
| 一時ダイス    | 六角形の左右に雲状の補助記号            | 曲線の形状、配置        |
| 即時リロール | リロールアイコン＋雷マーク | 傾き、波紋・雷マークの形状 |
| 特殊面の即時適用 | 星型入りひし形＋雷マーク              | 雷マークの形状、サイズ、配置  |
| ストック     | やや傾いた長方形のカードを縦に積み重ねた図柄    | 枚数、傾き、重なり方      |
| 数値表現     | 増減は＋N／−N、個数・回数は×Nを基本とする   | 今後追加される効果との整合性  |
