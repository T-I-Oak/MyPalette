# My Palette その他の効果仕様

## 1. 目的

本書は、My Paletteに登場する名声、カード、特殊面に関する効果の種類、パラメータ、アイコン表現を定義する。

アイコンの基本図形、色、画材記号、数値表記などの共通規則は「My Palette 効果共通仕様」に従う。

---

## 2. 名声に関する効果

### 2.1 名声値の変更

#### 効果の定義

名声値を指定された値Nだけ変化させる。

Nは0以外の整数とする。

* N > 0：名声値をN増加させる。
* N < 0：名声値を|N|減少させる。

#### アイコン表現

月桂冠の内側に、増減値を表示する。

* **増加時：** 月桂冠の内側に「＋N」を表示する。
* **減少時：** 月桂冠の内側に、赤文字で「−N」を表示する。

月桂冠と数値を一体のアイコンとして扱う。

---

## 3. カードに関する効果

### 3.1 カードのドロー

#### 効果の定義

山札からカードをN枚ドローする。

Nは1以上の整数とする。

#### アイコン表現

**扇形に広げたカード＋左向き矢印＋N**

3枚程度のカードを扇形に広げた図柄を使用する。

この図柄は、個別のカードではなく手札という集合を表す。

左向き矢印を組み合わせ、カードが手札に加わることを表す。

ドローによる手札の増加枚数を「＋N」で示す。

「＋1」は省略しない。

#### 表示例

* `[手札] [←] ＋1`
* `[手札] [←] ＋3`

### 3.2 ストックからのカード獲得

#### 効果の定義

ストックから絵画カードをN枚獲得する。

Nは1以上の整数とする。

#### アイコン表現

**左向き矢印＋ストックアイコン＋×N**

ストックアイコンには、やや傾いた長方形のカードを縦に積み重ねた専用図柄を使用する。

左向き矢印を組み合わせ、ストックからカードを獲得することを表す。

獲得枚数は「×N」で示す。

N＝1の場合は「×1」を省略できる。

#### 表示例

* `[←] [ストック]`：公開カードを1枚獲得する。
* `[←] [ストック] ×2`：公開カードを2枚獲得する。

### 3.3 手札のカードのステップ変更

#### 効果の定義

手札のカード1枚について、現在ステップを指定された値に変更する。

指定できるステップは、0・1・2のいずれかとする。

変更後のステップは絶対値で指定する。

#### アイコン表現

**ペン＋ステップ番号入りの長方形**

長方形は個別のカードを表す。

長方形の内部に、変更後のステップ番号を配置する。

ステップ番号は増減値ではなく変更後の状態を指定するため、「＋」「−」「×」は付けない。

#### 表示例

* `[ペン] [長方形〈0〉]`
* `[ペン] [長方形〈1〉]`
* `[ペン] [長方形〈2〉]`

### 3.4 手札交換

#### 効果の定義

手札のカード1枚を捨て札にし、カードを1枚ドローする処理をN回繰り返す。

Nは1以上の整数とする。

#### アイコン表現

**扇形に広げたカード＋双方向矢印**

扇形のカードは手札を、双方向矢印はカードの入れ替えを表す。

交換するカードの枚数は「×N」で表す。

N＝1の場合は「×1」を省略できる。

交換によって手札の枚数が増えるわけではないため、「＋1」は使用しない。

#### 表示例

`[手札] [↔]`

## 4. 特殊面に関する効果

### 4.1 現在出ている特殊面の効果を即時に得る

#### 効果の定義

効果の発動時点で、所持する未使用ダイスに現在出ている特殊面をすべて確認する。消費済みダイスは対象に含めない。

その時点で存在する特殊面を処理対象として確定する。

対象となる特殊面が複数ある場合は、すべての効果を得る。

同じ効果の特殊面が複数ある場合も、それぞれの効果を得る。

効果は次の順序で処理する。

1. 名声値の変更
2. カードのドロー
3. 一時ダイスの獲得とロール

処理中に新たに獲得したダイスは、今回確定した特殊面の処理対象に追加しない。

この効果は、特殊面の効果を追加で発動するものであり、ダイスを消費しない。ターン終了時にそのダイスが未使用の特殊面ダイスであれば、通常どおり効果を予約して消費する。

#### アイコン表現

**特殊面アイコン＋雷マーク**

ひし形の内部に星型を配置した特殊面アイコンと、雷マークを組み合わせる。

各要素は、以下の意味を持つ。

* ひし形：ダイス面
* 星型：特殊面全体
* 雷マーク：効果の即時適用

個々の特殊面の種類は指定せず、未使用ダイスに現在出ている特殊面すべてを対象とすることを表す。

#### 表示例

`[ひし形〈星型〉] [⚡]`

### 4.2 特殊面の種類

特殊面には、以下の9パターンが存在する。

| 効果                | パターン数 |
| ----------------- | ----: |
| 名声値＋1             |     1 |
| 通常構成の一時ダイス×1      |     1 |
| 色指定の一時ダイス×1（補色2色） |     3 |
| 画材指定の一時ダイス×1      |     3 |
| カードのドロー＋1         |     1 |
| **合計**            | **9** |

それぞれの特殊面には、その効果に対応するアイコンを使用する。

一時ダイスを1個獲得する特殊面では、「×1」を省略できる。

特殊面をまとめて指す場合には、星型を共通記号として使用する。
