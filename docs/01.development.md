# My Palette 開発環境

## 前提

- Node.js 22.12.0以上とnpm 10以上。初期確認環境はNode.js 25.6.1、npm 11.9.0。
- 共通リポジトリ `T-I-Oak/GameWorksOAK` を、このゲームと隣接する `../GameWorksOAK/` に配置する。
- 共通規約は `../GameWorksOAK/docs/common/09.game_setup.md` から参照する。ゲーム側から共通部は編集しない。

## コマンド

ゲームのリポジトリ直下で、一つずつ実行する。

- 依存復元: `npm.cmd ci`
- 開発起動: `npm.cmd run dev`
- 全テスト: `npm.cmd test`
- 本番ビルド: `npm.cmd run build`
- ビルド確認: `npm.cmd run preview`

Viteのbaseは相対パス、出力先は `dist/`。既存素材は `public/assets/` に保持する。
バージョンは `package.json` を唯一の設定元とし、共通Env Utilityを通して確認画面に表示する。

## 構成

- `docs/requirements/`: ゲーム要求仕様。
- `docs/planning/`: バックログと開発フェーズの成果物。
- `src/`: 起動入口、スタイル、共通ライブラリ接続。
- `public/`: 既存画像などの静的素材。
- `scripts/`: 補助スクリプト。
- `tests/spec/`: 要求仕様の章に対応する受入テスト。ゲーム実装時に追加する。
- `tests/implementation/`: 実装に対応するテスト。

## Gitと作業範囲

初期構築のバージョンは `0.0.0`、正系ブランチは `master`。
ゲーム本体は未実装。開発ブランチは計画フェーズでスコープ・バージョン・ブランチ名に合意してから作成する。
公開設定、ポータル登録、CIは未設定。リモートは保存先の指定後に設定する。

## 環境構築の検証

- `npm.cmd test`: 共通Env Utilityと設定値の接続テスト1件成功。
- `npm.cmd run build`: Vite 7.3.7による本番ビルド成功。
- Edgeのヘッドレス実行で1280×720、768×1024、390×844を確認。入口・画像はHTTP 200、バージョン表示は0.0.0、ページのはみ出しとJavaScriptエラーはなし。
- ブラウザ検証は隣接ゲームの既存Playwrightを一時利用。MyPaletteの必須依存には含めない。
- 事前配置の仕様書7件・画像58件はSHA-256照合で変更・欠落なし。
- 依存取得はサンドボックス内のDNS解決で失敗したため、許可されたネットワーク環境で実施。
